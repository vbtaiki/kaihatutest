# ドイツ書店事例

## 📊 概要：世界最強の「共同流通」インフラ

ドイツには日本と同じく「再販制度」があるが、書店数は維持されており、物流の効率はアメリカ以上。**世界で最も洗練された出版流通**と言われている。

### なぜドイツは成功しているのか？

| 共通点 | ドイツ | 日本 |
|-------|-------|------|
| 再販制度 | ✅ あり | ✅ あり |
| 定価販売 | ✅ あり | ✅ あり |

| 違い | ドイツ | 日本 |
|-----|-------|------|
| 流通方式 | **直取引・買い切り** | 委託販売・返品可 |
| 卸の役割 | 書店のバックオフィス | 配本の中央管理 |
| 配送速度 | **翌朝配送が標準** | 数日かかることも |

**→ 同じ再販制度でも、流通構造の違いで明暗が分かれた**

## 🏭 主要卸会社（ブーフ・グロス・アンティクヴァリアート）

### リブリ（Libri）

ドイツ最大級の書籍卸商。イングラムに近い機能を持つ。

| 機能 | 内容 |
|-----|------|
| **オーバーナイト・デリバリー** | 全国のどこの書店でも、夕方までに注文すれば**翌朝には本が届く** |
| **在庫管理システム提供** | 書店の在庫管理やECサイトを構築・提供 |
| **数十年の実績** | この仕組みを数十年前から実現している |
| **書店のIT代行** | 発注システム、顧客管理、在庫分析まで一括提供 |

### KNV（Koch, Neff & Volckmar）

リブリと並ぶ大手卸会社。同様の高速物流・IT支援を提供。

## 🔧 「卸が書店のバックオフィスを担う」モデルの詳細

### ドイツ型流通の特徴

```
【ドイツ】
出版社 ──→ 書店（直接）
        └→ 卸会社 ──→ 書店
           （リブリ/KNV）
           ※注文買い切り
           ※翌朝配送
           ※IT・システム支援
```

```
【日本】
出版社 ──→ 取次 ──→ 書店
         （日販・トーハン）
         ※委託販売（返品可）
         ※自動配本
         ※書店の選書権限が弱い
```

### 卸が提供するサービス一覧

| サービス | 内容 |
|---------|------|
| **発注システム** | 書店がリアルタイムで在庫確認・発注可能 |
| **翌朝配送** | 夕方注文→翌朝到着が標準 |
| **ECサイト構築** | 独立系書店でもAmazonに対抗できるEC機能 |
| **在庫分析** | どの本が売れているか、データ提供 |
| **決済代行** | 出版社との精算を卸が代行 |
| **返品処理** | 効率的な返品ルートの提供 |

## 🔑 成功の鍵：「書店のバックオフィス」として機能

### 日本との決定的な違い

| 項目 | ドイツ | 日本 |
|-----|-------|------|
| **配送スピード** | 翌朝配送が標準 | 数日かかることも |
| **IT支援** | 卸が書店のシステムを丸ごと提供 | 各社バラバラ |
| **再販制度** | あり（日本と同じ） | あり |
| **書店の競争力** | **Amazonと同等の利便性**を実現 | Amazonに劣る |
| **選書権限** | 書店が自由に選べる | 取次の配本に依存 |
| **粗利率** | 高い（買い切りのリスク分） | 低い（22-23%） |

### 書店の強み

卸のシステムを使うことで、自前で在庫を持たなくても**Amazonと同等の利便性**を客に提供できる。

> 「お客様が欲しい本を、明日の朝には届けられる」

これが小さな独立系書店でも可能になっている。

## 🇫🇷 参考：フランスの流通モデル

フランスも再販制度があり、独自の流通構造を持つ。

| 特徴 | 内容 |
|-----|------|
| **流通経路** | 出版社 → **出版社運営の取次** → 書店 |
| **卸の性質** | 出版社グループが自前で卸機能を運営 |
| **買い切り** | 基本は買い切り制 |

**→ 日本の取次とは異なり、出版社側がコントロール**

## 🎯 バリューブックスへのヒント

### 1. 「物流屋」ではなく「書店のバックオフィス」になる

埼玉倉庫が単なる「古本の保管場所」ではなく、提携書店の在庫を24時間コントロールする**「クラウド倉庫」**に。

| 現状 | 目指す姿 |
|-----|---------|
| 古本の保管・発送拠点 | 独立系書店の**共有バックオフィス** |
| VBのための倉庫 | 提携書店**全員**のための倉庫 |

### 2. 高度なIT支援

- 独立系書店向けの発注・在庫管理ツールを自社開発
- 「どの本が今、中古市場でも価値が落ちていないか」というデータを提供
- **「この本は仕入れるべき」というレコメンド機能**

### 3. 翌日配送の実現

- 効率的な物流網を構築し、「注文したら翌日届く」を標準に
- 独立系書店が「VBと提携していれば、Amazonと同じスピードで本を届けられる」状態を作る

### 4. 「日本の独立系書店が最も求めているサポート」

ドイツの「卸会社が書店のITインフラをすべて担う」という点は、日本の独立系書店が最も求めているサポート。

> VBがこのポジションを取れれば、日本の書店界で新しい秩序が生まれる

## 📊 ドイツモデルの特徴まとめ

| キーワード | 内容 |
|-----------|------|
| **リブリ/KNV** | 最大手の卸会社 |
| **翌朝配送** | 全国標準のサービス |
| **再販維持** | 日本と同じ定価制度 |
| **卸によるIT支援** | 書店のシステムを卸が提供 |
| **直取引・買い切り** | 委託販売ではない |
| **書店の自律性** | 選書権限は書店にある |

## 💡 ドイツから学ぶ最大の教訓

> **再販制度があっても、流通構造を変えれば書店は生き残れる**

日本は「再販制度があるから変えられない」と言い訳しがちだが、ドイツは同じ制度下で成功している。違いは**卸の役割**と**書店への権限委譲**。

バリューブックスが「日本版リブリ」になれば、日本の書店風景は変わる。
