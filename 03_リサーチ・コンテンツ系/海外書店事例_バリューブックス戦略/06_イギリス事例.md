# イギリス書店事例

## 📊 概要：「ドーント革命」の原点

イギリスは、アメリカで書店チェーン復活を成し遂げた**ジェームズ・ドーント**の原点であり、「再販制度なき世界」で独立系書店がいかに生き残るかの実験場。

また、**古本・チャリティショップ文化**が最も成熟しており、バリューブックスのビジネスモデルに直結する示唆が多い。

---

## 🏛️ イギリス出版流通の特徴

### 再販制度の廃止（1995年）

| 項目 | 内容 |
|-----|------|
| **Net Book Agreement** | 1900年〜1995年まで存在した再販制度 |
| **廃止後の影響** | 価格競争が激化、大手チェーン・Amazonが優位に |
| **独立系書店** | 一度は壊滅的打撃を受けた |

**→ 日本が「再販制度を維持したまま改革する」際の反面教師**

### 流通構造

```
【イギリス】
出版社 ──→ 書店（直取引）
        └→ 卸会社（Gardners, Bertrams）──→ 書店
           ※買い切りが基本
           ※返品は可能だが条件付き
```

| 特徴 | 内容 |
|-----|------|
| **主要卸** | Gardners（ガードナーズ）、Bertrams（バートラムズ） |
| **仕入れ方式** | 買い切りが主（日本の委託販売とは異なる） |
| **価格設定** | 書店が自由に決定（再販制度なし） |
| **粗利** | 約35〜45%（買い切りリスクを反映） |

## 👤 キーマン：ジェームズ・ドーント（James Daunt）

### イギリスでの実績

| 年 | 出来事 |
|----|-------|
| **1990年** | ロンドンで「Daunt Books」創業 |
| **2011年** | 瀕死の**ウォーターストーンズ（Waterstones）**のCEOに就任 |
| **2017年** | ウォーターストーンズを**黒字化** |
| **2019年** | アメリカ「バーンズ＆ノーブル」CEOに就任 |

### ウォーターストーンズ再建の手法

ウォーターストーンズは2011年時点で年間数千万ポンドの赤字を抱えていた。

| 改革 | 内容 |
|-----|------|
| **中央集権の廃止** | 本部による「この本を置け」指示を撤廃 |
| **有料棚（Co-op）の廃止** | 出版社が金を払って目立つ場所に置く慣習を終了 |
| **店舗ごとの個性化** | 各店長に選書・陳列の全権限を委譲 |
| **カフェ・イベント強化** | 体験型書店への転換 |
| **ECの縮小** | Amazonとの価格競争から撤退、店舗体験に集中 |

### ドーントの名言（イギリス時代）

> 「書店員は本を売る人間であって、棚に並べる機械ではない」

**→ この思想がアメリカのB&N再建、そして「分権型運営」の原点**

## 🏪 ウォーターストーンズ（Waterstones）

イギリス最大の書店チェーン。約280店舗を展開。

### 特徴

| 項目 | 内容 |
|-----|------|
| **店舗数** | 約280店舗（イギリス全土） |
| **コンセプト** | 「各店舗が独立した書店」として機能 |
| **品揃え** | 店舗ごとに大きく異なる（地域性を反映） |
| **イベント** | 著者トーク、読書会を積極開催 |

### 2011年 vs 現在

| 指標 | 2011年 | 現在 |
|-----|--------|------|
| **収益性** | 赤字（数千万ポンド） | 黒字 |
| **返品率** | 高い | 大幅低下 |
| **従業員士気** | 低い | 高い |
| **Amazon対抗** | 敗北 | 共存（棲み分け） |

## 📚 イギリスの古本・チャリティ文化

### Charity Shops（チャリティショップ）

イギリス独自の文化で、**古本を「社会貢献」として流通させる仕組み**が発達。

| 組織 | 内容 |
|-----|------|
| **Oxfam Books** | 国際NGO「オックスファム」が運営する古本チェーン |
| **British Heart Foundation** | 心臓病チャリティの古本店 |
| **Cancer Research UK** | がん研究チャリティの古本店 |

### チャリティショップの仕組み

1. 市民が不要な本を**寄付**
2. チャリティが店頭で販売
3. 売上は**社会貢献活動**に充当
4. 購入者は「社会に良いことをした」という満足感

**→ バリューブックスの「charibon（チャリボン）」と同じ発想**

### World of Books

イギリス発の**大規模オンライン古本販売**企業。

| 特徴 | 内容 |
|-----|------|
| **在庫数** | 数百万冊 |
| **調達方法** | チャリティショップとの提携、買取 |
| **販売チャネル** | Amazon、eBay、自社サイト |
| **環境訴求** | 「本を救う」というメッセージ |

**→ バリューブックスの「大規模古本EC」に近いモデル**

## 🛒 イギリスの独立系書店

### BA（Booksellers Association）

イギリスの書店組合。アメリカのABAに相当。

| 機能 | 内容 |
|-----|------|
| **会員支援** | 経営相談、法務支援 |
| **共同仕入れ** | 卸会社との交渉力強化 |
| **イベント** | Independent Bookshop Week |
| **データ提供** | 売上統計、トレンド分析 |

### 独立系書店の復活

| 指標 | 動向 |
|-----|------|
| **店舗数** | 増加傾向 |
| **主な成功要因** | 地域密着、専門特化、イベント重視 |
| **課題** | 家賃高騰、人件費 |

### 注目の独立系書店

| 書店名 | 特徴 |
|-------|------|
| **Daunt Books** | ドーント本人の店。美しい内装で有名 |
| **Foyles** | ロンドン最大の独立系。多層階の巨大書店 |
| **Hatchards** | 1797年創業。イギリス最古の書店 |
| **Mr B's Emporium** | バースの体験型書店。「読書処方箋」で有名 |

## 🎯 バリューブックスへの示唆

### 1. 「再販制度なき世界」の教訓

イギリスは1995年に再販制度を廃止し、価格競争でAmazonに敗北した。しかしその後、**「価格ではなく体験で勝負」**する書店が復活。

> **日本は再販制度を維持しながら、イギリスの「体験重視」を取り入れるべき**

### 2. チャリティ×古本モデル

イギリスの「Charity Shops」は、バリューブックスの「charibon」の完成形。

| 学ぶべき点 | 内容 |
|-----------|------|
| **社会貢献ブランディング** | 「古本を買う＝社会に良いこと」という認知 |
| **調達ルートの多様化** | 寄付、買取、提携の組み合わせ |
| **地域コミュニティとの連携** | 地元チャリティとの協働 |

### 3. World of Booksモデル

大規模オンライン古本販売の成功例として、VBが目指すべき方向性を示している。

| 参考点 | 内容 |
|-------|------|
| **大量在庫管理** | 数百万冊の効率的管理 |
| **マルチチャネル販売** | 自社サイト＋マーケットプレイス |
| **環境メッセージ** | 「本を救う」という訴求 |

### 4. ドーント流「分権化」の原点

ウォーターストーンズでの成功体験が、後のB&N再建につながった。

> **「各店舗に権限を委譲する」というドーントの思想は、VBが独立系書店と組む際の基本原則になる**

## 📊 イギリスモデルの特徴まとめ

| キーワード | 内容 |
|-----------|------|
| **再販制度なし** | 1995年廃止、価格自由競争 |
| **ウォーターストーンズ** | 最大手チェーン、ドーントが再建 |
| **分権型運営** | 各店舗に選書・陳列権限を委譲 |
| **チャリティショップ** | 古本×社会貢献の成熟文化 |
| **World of Books** | 大規模オンライン古本販売 |
| **独立系復活** | 体験・専門特化で生き残り |

---

## 💡 イギリスから学ぶ最大の教訓

> **「再販制度がなくても、価格競争から逃げて体験で勝負すれば書店は生き残れる」**

日本は再販制度があるため、イギリスより有利な立場にある。その上で、イギリスの「チャリティ×古本」「分権型運営」「体験重視」を取り入れれば、より強い書店エコシステムを作れる。
