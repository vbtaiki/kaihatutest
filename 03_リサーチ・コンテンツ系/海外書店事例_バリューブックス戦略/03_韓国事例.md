# 韓国書店事例

## 📊 概要：委託販売システム下での復活劇

韓国はかつて日本以上に書店が減少したが、最大手の**教保文庫（キョボムンゴ）**が物流と店舗体験を再定義して復活した。

### 重要なポイント

> **韓国は日本と同じ「委託販売システム」**を採用している

つまり、韓国の成功は「日本型システム内での工夫」であり、バリューブックスにとって最も直接的な参考になる。

---

## 📈 韓国書店市場の回復

| 項目 | 状況 |
|-----|------|
| **市場動向** | 拡大中（↑） |
| **政策支援** | **強い**（公的支援で回復） |
| **流通方式** | 委託販売（日本と同じ） |
| **特徴** | OMO戦略で成功 |

**→ 公的支援＋独自戦略の組み合わせで復活**

## 🏪 教保文庫（キョボムンゴ）

韓国最大手の書店チェーン。ソウル光化門の巨大フラッグシップ店が有名。

### 「バロバロ」サービス（即時受け取り）

| 項目 | 内容 |
|-----|------|
| **仕組み** | オンラインで注文し、**1時間後**に最寄りの実店舗で受け取れる |
| **コンセプト** | OMO（Online Merges with Offline） |
| **価値** | ネットの利便性と、書店の「歩き回る楽しさ」を完全に統合 |

### OMO（Online Merges with Offline）戦略

オンラインとオフラインの境界を完全に消した。

- **オンラインで注文** → **リアル店舗で受け取り**
- リアル店舗に来た客が店内を回遊し、追加購入につながる
- 「受け取りのためだけ」ではなく**「体験」**として機能

## 🏛️ 韓国の公的支援

日本と大きく異なる点として、韓国は**政府による書店支援が手厚い**。

| 支援内容 | 詳細 |
|---------|------|
| **書店振興法** | 独立系書店への財政支援 |
| **出版文化産業振興** | 読書推進キャンペーン |
| **公共図書館連携** | 地域書店での購入促進 |

**→ 日本は最近になって経産省主導の支援が始まったばかり**

## 🎯 バリューブックスへのヒント

### 「受け取り拠点」としての独立系書店

バリューブックスのECサイトで買った本を、提携している各地の独立系書店で受け取れる仕組みを作る。

| メリット | 内容 |
|---------|------|
| **書店側** | 受け取り手数料が入る |
| **顧客側** | 送料節約、すぐ受け取れる |
| **VB側** | 地域の書店を「自社の受け取り拠点」として味方に付けられる |
| **相乗効果** | 受け取りに来た客が書店で追加購入する可能性 |

### 具体的イメージ

1. バリューブックスで古本を購入
2. 「受け取り場所」として近隣の提携書店を選択
3. 書店に本が届いたら通知
4. 客が書店を訪れ、本を受け取りながら店内を回遊
5. 書店には手数料、客には便利さ、VBには物流コスト削減

### 「1時間受け取り」の日本版

教保文庫の「1時間受け取り」は、物流網が整っているからこそ実現できる。

バリューブックスの場合：

| ステップ | 実現方法 |
|---------|---------|
| **Phase 1** | 「翌日受け取り」から開始 |
| **Phase 2** | 拠点書店に在庫を分散配置 |
| **Phase 3** | 主要都市で「当日受け取り」を実現 |

## 💡 韓国から学ぶ最大の教訓

> **委託販売システムでも、OMO戦略と公的支援があれば復活できる**

日本は委託販売システムを変えることが難しいとされている。しかし韓国は同じシステム下で、以下の工夫で復活した：

1. **OMO戦略**：オンラインとオフラインの融合
2. **公的支援**：政府による財政・制度支援
3. **ハイブリッドモデル**：新刊と中古の共存

バリューブックスは「公的支援」を待つのではなく、**自ら韓国型のOMOインフラを構築**することで、日本の独立系書店の「救世主」になれる可能性がある。
