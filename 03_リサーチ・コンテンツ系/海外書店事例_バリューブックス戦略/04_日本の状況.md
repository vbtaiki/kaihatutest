# 日本の書店・出版流通の状況

## 📊 概要：構造的な「負のループ」

日本の書店数は、この20年で約半分に減少。**ビジネスモデルそのものが限界**を迎えている。

---

## 📉 危機的な数値（2023-2024年）

| 指標 | 数値 | 備考 |
|-----|------|------|
| **現在の書店数** | 10,918店 | 10年前から**3割以上減少** |
| **年間閉店数** | 614店舗 | **1日1軒以上**が閉店 |
| **年間新規開店** | 92店舗 | 圧倒的に閉店が上回る |
| **書店のない市区町村** | **27.9%** | 全国の約4分の1 |
| **紙出版市場ピーク** | 2兆6,564億円（1996年） | - |
| **現在の紙出版市場** | 1兆612億円（2023年） | ピークの**40%**に激減 |

### 日米比較：衝撃的な対称性

| 国 | 書店の動向（年間） |
|----|------------------|
| 🇺🇸 アメリカ | **+323店**（新規開業） |
| 🇯🇵 日本 | **-614店**（閉店） |

> **日本だけが「30年間右肩下がり」という世界的に見ても特異な現象**

## ❌ 書店衰退の3つの構造的原因

### 1. 「雑誌」という収益源の消失

日本の町の本屋を支えていたのは、実は本ではなく**「雑誌」**だった。

| 項目 | 内容 |
|-----|------|
| **雑誌売上ピーク**（1997年） | 高水準 |
| **2022年の雑誌売上** | ピークの**3割未満**に激減 |
| **雑誌の役割** | 「薄利多売」で書店経営の支柱だった |
| **配送の仕組み** | 書籍がトラックに「便乗」する形で配送されていた |

**→ スマホ（SNS、dマガジン等）に完全に食われた**

### 2. 再販制度と低い粗利

| 項目 | 内容 |
|-----|------|
| **再販制度** | どこでも同じ値段で買える（価格競争不可） |
| **書店の粗利** | 約**22〜23%**と非常に低く**固定** |
| **必要な粗利** | **30%以上** |
| **価格調整** | 光熱費や人件費が上がっても価格を上げられない |
| **結果** | 売れば売るほど苦しい状態 |

### 3. 配本システムのミスマッチ

| 項目 | 内容 |
|-----|------|
| **取次（問屋）** | 自動的に本を送ってくる仕組み |
| **かつての効率性** | 全国に新刊を届けるのに優れていた |
| **現在の問題** | 「売れない本が届き、返品作業に追われる」現場の疲弊 |
| **返本率** | **高水準**（目標は20%以下） |

## 💸 コスト急増の現実

| コスト項目 | 状況 |
|-----------|------|
| **最低賃金** | 800円→**1,500〜1,700円**へ急騰 |
| **賃料** | 商業施設での優遇措置が消滅、不動産高騰 |
| **光熱費** | 上昇 |
| **相続税問題** | 地価高騰→固定資産税→相続税に連動 |

**→ 老舗書店が相続のタイミングで閉店するケースが増加**

## 🏭 日本の取次システム

### 主要取次

- **日販（日本出版販売）**
- **トーハン**

### 取次の機能

| 機能 | 内容 |
|-----|------|
| **配本** | 取次が店舗へ「自動的に」送る |
| **返品** | 委託販売（一定期間なら返品自由） |
| **金融** | 書店への支払猶予など金融支援が強い |

---

## 📊 日本とアメリカの取次比較（詳細版）

| 機能 | 日本（日販・トーハン等） | アメリカ（イングラム等） |
|-----|---------------------|---------------------|
| **配本権限** | 取次が店舗へ「自動的に」送る | 書店が「必要な分だけ」注文する |
| **返品権限** | 委託販売（一定期間なら返品自由） | 原則買い切り（返品は手数料等で制限） |
| **利益率（粗利）** | 約**22〜23%**（固定） | 約**40〜50%**（交渉や量で変動） |
| **金融機能** | 書店への支払猶予など金融支援が強い | 純粋な「物流・システム提供」に近い |
| **書店の選書権限** | **弱い**（配本に依存） | **強い**（自分で選ぶ） |
| **IT支援** | 各社バラバラ | 卸が一括提供 |

## 🌍 世界との流通構造比較

| 国 | 流通型 | 特徴 |
|----|-------|------|
| **アメリカ** | 直取引・買い切り | 出版社→書店（イングラム等経由） |
| **ドイツ** | 買い切り | 出版社→卸→書店（翌朝配送） |
| **イギリス** | 買い切り | 出版社→書店（直） |
| **フランス** | 買い切り | 出版社→出版社運営の卸→書店 |
| **日本** | **委託販売** | 出版社→取次→書店 |
| **韓国** | **委託販売** | 出版社→取次→書店 |

> **日本と韓国だけが「委託販売」という世界的に見ても例外的な構造**

|----|------------|
| アメリカ | **50%** |
| タイ | **70%** |
| オーストラリア | **80%** |

**→ 海外では「取次を介さない」のが普通**

## ⚖️ 定価（再販制度）の違い

| 項目 | 日本（再販制度あり） | アメリカ（自由価格制） |
|-----|------------------|-------------------|
| **価格の決定権** | 出版社が決定（全国一律） | **小売店（書店）**が最終決定 |
| **書店の粗利** | 約22〜23%（固定） | 約40〜50%（仕入れ努力で変動） |
| **値引き** | 原則不可（ポイント付与等のみ） | 自由（ベストセラーを40%引で売る等） |
| **返品** | 委託販売（基本は返品可） | 原則買い切り（返品には条件・コストあり） |

### ポイント

アメリカの書店は「買い切り」というリスクを負う代わりに、**「1冊売った時の利益が日本の2倍」**ある。この利益があるからこそ、カフェを併設したり、イベントを企画したりする「余裕」が生まれる。

## 📉 日販・トーハンのジレンマ

### 抱えている問題

1. **雑誌の衰退**：収益の柱が崩壊
2. **返品率の高さ**：物流コストの増大
3. **2024年問題**：配送料の上昇で「毎日配送」の維持が困難
4. **既存システムの重さ**：小回りが利かない
5. **デジタル化の遅れ**：IT投資の不足

一方で、日本でもアメリカのような**「新しい独立系書店」**は少しずつ増えている。

| タイプ | 例 |
|-------|-----|

### 二極化する未来

| 消えていく | 残っていく |
|-----------|-----------|
| 雑誌と新刊を並べる「コンビニ型」の本屋 | 店主の思想が反映された空間 |
| 画一的な品揃え | キュレーションの個性 |

## 💡 バリューブックスへの示唆

### 日本の中小出版社が抱える課題

1. **在庫保管料**に苦しんでいる
2. **物流・データ管理（血管・心臓）**が脆弱
3. 「編集（脳）」は優れているが、インフラがない

### バリューブックスが提供できる価値

> 「社名はそのまま、編集権もそのまま。でも、在庫管理、発送、データ分析、そして古本を含めた二次流通の管理まで、すべてバリューブックスのOSの上でやりませんか？」

### 「バーチャル・グループ化」

資本関係で買収するのではなく、**「物流とデータのプラットフォーム」**で中小出版社を束ねる。

アメリカのBig 5のような「効率性」と、独立系出版社の「多様性」を両立した新しい勢力に。

### チャンスの窓

> **日販・トーハンがジレンマを抱えている今こそ、「日本版イングラム」の立ち位置を確立するチャンス**
