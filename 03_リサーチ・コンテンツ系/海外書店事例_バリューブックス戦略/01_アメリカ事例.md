# アメリカ書店事例

## 📊 概要：どん底からの「体験型」への進化

2010年頃に大手チェーンのボーダーズ（Borders）が倒産するなど、アメリカの書店は一度壊滅的な状況になった。しかし、そこから独立系書店がV字回復している。

## 🏭 イングラム（Ingram Content Group）徹底分析

### 基本情報

イングラムは単なる「取次（卸）」ではなく、**「世界最大のオンデマンド印刷工場」と「出版社の全業務アウトソーシング先」**を兼ね備えた、出版業界のOS（基盤）。

### Lightning Source（オンデマンド印刷部門）

| 項目 | 内容 |
|-----|------|
| **使用機器** | HP PageWide シリーズ（高速インクジェット輪転機）を中心とした完全自動化ライン |
| **最小ロット** | 1冊から製造可能 |
| **平均生産時間** | 注文から発送まで24〜48時間以内 |
| **品質** | オフセット印刷に近い品質 |

### 「仮想在庫（Virtual Inventory）」という発明

出版社は本を1冊も倉庫に置く必要がない。データだけをイングラムに預けておけば、注文が入った瞬間に「製造→発送」される。

**→ 出版社の最大の悩み「在庫リスク（保管料・廃棄コスト）」がゼロに**

### 在庫戦略：通常印刷とPODの共存

| カテゴリ | 対応方法 |
|---------|---------|
| **売れ筋（ベストセラー）** | 通常のオフセット印刷本を出版社から大量に仕入れて在庫 |
| **ロングテール（低頻度）** | 自動的にPOD（オンデマンド）に切り替え |

**ハイブリッド在庫**：出版社に対し「在庫が切れたら自動的にPODに切り替えて販売を継続する」オプションを提供。「品切れによる機会損失」を物理的にゼロに。

## 📦 出版社との多層的パートナーシップ

### ① IngramSpark（小規模・個人出版社向け）

「誰でも出版社になれる」プラットフォーム。

- PDFをアップロードするだけで、世界中の4万以上の書店のカタログに自動登録
- 印刷・配送・代金回収はすべてイングラムが代行
- 出版社は宣伝だけに集中

### ② IPS - Ingram Publisher Services（中堅・大手向け）

イングラムが「出版社の営業部・物流部」を代行するサービス。

- 物流だけでなく、**全米の書店への営業（セールス・レップ）**も代行
- イングラムの営業マンが独立系書店に新刊を売り込む
- 自社で営業網を持てないニッチな出版社でも全米展開が可能に

### ③ Global Connect（国際展開）

DNP（大日本印刷）も提携している仕組み。

- 「国境を越えるのはデータだけ」というモデル
- アメリカの出版社の本を、日本で注文が入った瞬間に日本の提携工場で刷って届ける
- 輸送コストと時間を物理的にゼロに

### インプリント（Imprint）戦略

買収された出版社は名前を消されることは稀。その名前（ブランド）を「インプリント」として残す。

| 維持されるもの | 統合されるもの |
|--------------|--------------|
| 社名（レーベル名） | 物流 |
| 編集権（どの本を出すか） | 販売・宣伝 |
| 作家との契約権 | 人事・法務 |
|  | インフラ（システム） |

**例**：ペンギン・ランダムハウスの中には250以上の独立したインプリントが存在。同じグループ内のインプリント同士で一人の作家を巡って競り合うこともある。

## 👤 キーマン：ジェームズ・ドーント（James Daunt）

独立系書店のマインドを「巨大チェーン」に持ち込んで成功させた、業界で最も注目される人物。

### 経歴

1. **1990年**：ロンドンで「Daunt Books」という美しい独立系書店を創業
2. **2011年**：イギリス最大手チェーン「ウォーターストーンズ」CEO就任 → **2017年黒字化**
3. **2019年〜**：アメリカ最大の書店チェーン「バーンズ・アンド・ノーブル（B&N）」のCEO

### B&Nで行った「分権型運営」革命

> 「600店舗の巨大な独立系書店の集合体」に変える

| 改革 | 内容 |
|-----|------|
| **中央集権の廃止** | 本部が一括で決めるのをやめ、各店舗の書店員に選書・陳列の権限を返した |
| **広告料（有料棚）の拒否** | 出版社がお金を払って新刊を目立つ場所に置く慣習を**廃止** |
| **返品率の劇的低下** | 現場主導の選書で売れ残りが激減、収益性が改善 |
| **内部昇進重視** | 書店員以外のマネージャー配置を廃止、専任書店員の組織化 |

### 成果

- **2025年**：60店舗の新規開業予定
- **2026年**：同規模の展開を継続予定
- 過去15年間で100店以上閉鎖していた状態から**完全復活**

### ドーントの名言

> 「皮肉なことに、責任を店舗ごとに下ろすと、彼らははるかに上手にやってくれるのだ」

**→ 日本の取次システムの中央集権性が「非効率の原因」であることを示唆**

## 🏪 注目すべき多店舗展開の成功モデル

### ① Powell's Books（パウエルズ・ブックス）

ポートランドに本拠を置く「世界最大の独立系書店」。

| 特徴 | 内容 |
|-----|------|
| **モデル** | 新刊と古本を同じ棚に並べる |
| **規模** | 1ブロック丸ごと書店 |
| **価値** | 「安く買いたい人は古本」「著者を応援したい人は新刊」を同じ場所で選べる |

**→ Value Booksのモデルに近い**

### ② McNally Jackson（マクナリー・ジャクソン）

ニューヨークで数店舗を展開する、今最もクールで収益性が高いと言われるグループ。

| 特徴 | 内容 |
|-----|------|
| **モデル** | 店舗ごとにデザインも選書も全く変える |
| **強み** | 規模を大きくせず、質を高く保ったまま店舗数を増やす |
| **特別機能** | 店内に「エスプレッソ・ブック・マシン」（オンデマンド印刷機）を設置 |

| **両立** | 効率的な中古流通 × ワクワクする宝探し体験 |

## 🏛️ ABA（全米書店組合）& Bookshop.org

### ABA（American Booksellers Association）

個人だけでなく、組織としてのキーマン。

- 独立系書店のDX（デジタルトランスフォーメーション）を支援
- **5年間で会員数1,000店以上増加**の立役者

### Bookshop.org

**「Amazonに対抗する独立系書店のEC連合」**

- 独立系書店の在庫をネットで買えるプラットフォーム
- 購入すると、指定した地元の独立系書店に利益が還元される仕組み
- 「Amazonで買うか、地元書店を応援するか」という選択肢を消費者に提供

## 💰 ビジネスモデルの違い（日本との比較）

| 項目 | アメリカ（独立系） | 日本（一般的な町の本屋） |
|-----|-----------------|---------------------|
| **仕入れ** | 買い切りが主（リスクを取る） | 委託販売（売れ残れば返品可） |
| **粗利** | **約40%〜**（高いがリスクあり） | **約22〜23%**（低いが返品可） |
| **価格** | 自由（割引も可能） | 定価販売（再販制度） |
| **役割** | 地域のコミュニティ・選書 | 新刊・雑誌の提供 |
| **卸との関係** | 書店が「必要な分だけ」注文 | 取次が店舗へ「自動的に」送る |
| **流通経路** | 出版社→書店（**直取引**） | 出版社→取次→書店 |

### 「買い切り」が生むプロ意識

返品できないリスクがあるからこそ、書店員は「この街の人が今読むべき本」を必死に選び抜く。この「選書を通じたコミュニティへの責任」が、Amazonに勝てる唯一の武器。

## 🎯 バリューブックスへの示唆

### イングラムから盗むべき「3つの牙城」

1. **「古本在庫」をPODのバックアップにする**
   - 新刊の在庫が切れたら、即座にバリューブックスの良品古本を公式ルートとして流通させる
   - 世界初の「古本連動型POD卸」

2. **埼玉倉庫の「24時間製造・出荷」体制**
   - 高速POD機を配置
   - ロングテールの古本とPODの新刊が同じ箱で書店に届く

3. **「データ」による出版プロデュース**
   - 「どの本が今、中古市場で高騰しているか（＝需要があるのに絶版）」というデータを活用
   - 出版社へ「PODでの復刊」を提案し、独占販売権を得る

### ドーント流「分権型モデル」の日本版活用

1. 独立系書店との協業時に「各店舗の自律性」を最大尊重
2. 中央集権的な指示ではなく、地域別・店舗別の専門化を支援
3. 古本×新刊のハイブリッド卸で、各店の利益構造を透明化

### 「新刊×古本ハイブリッド」モデルの正当性

**Troubled Sleeper**など、アメリカでも「新刊×古本ハイブリッド」モデルが成功し始めている。これはバリューブックスの「日本版イングラム構想」の強い根拠となる。
