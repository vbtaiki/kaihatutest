# サービス構想：読書伴走AI（Value Books Lens）

## 1. サービス概要

### コンセプト

> **「本を読む体験」を「AIとの対話体験」に拡張し、読書を孤独な行為から社会的なネットワークに変える**

ユーザーが本を読みながらAIと対話することで：
- 理解を深め
- 自分の文脈に接続し
- 次の行動につなげる

その記録がアーカイブされ、他の読者とも共有されることで、**読書体験のネットワーク**が形成される。

---

## 2. Geminiで実施した仮想体験

### 体験フロー

```
[ユーザー] 本を読み始める
    ↓
[ユーザー] 気になる箇所を写真に撮る / テキストを共有する
    ↓
[AI] ユーザーの文脈（仕事、家族、価値観）を踏まえて解説
    ↓
[対話] 「これは自分にとってどういう意味があるか？」を深掘り
    ↓
[AI] 次に読むべき本をレコメンド（ユーザーの今の状態に最適化）
    ↓
[アーカイブ] 対話履歴・インサイトを保存
    ↓
[共有] 他のユーザーにも一部公開（ソーシャル読書）
```

### 実際に行われた対話の例

| ステップ | 内容 |
|---------|------|
| 1. 本の選択 | 『The Art of Spending Money』を読み始める |
| 2. 文脈の共有 | 「IPO準備中」「レベル5からレベル6へ」「従業員の幸福」 |
| 3. 深掘り対話 | 「第7章を読んだが、もう知っている内容だった」 |
| 4. AIの判断 | 「守りはクリア済み。次は攻め（次世代への変換）へ」 |
| 5. レコメンド | ビジネス書→非ビジネス書→学術的死角の本へと進化 |
| 6. 自己発見 | 「既読リスト」から読書傾向が明確化 |

## 3. サービスの核心価値

### ❶ パーソナライズされた読書ガイド

- 単なる「おすすめ本リスト」ではない
- **ユーザーの今の状況**（仕事、家族、悩み、目標）に基づく
- 「この章は飛ばしていい」「ここだけ読めば元が取れる」

### ❷ 読書の「アウトプット」化

- 読んで終わりではなく、対話を通じて自分の言葉に変換
- 「明日の朝礼で語りたくなる言葉」を発見
- 行動（アクションプラン）につなげる

### ❸ 読書のソーシャル化

- 他のユーザーがこの本をどう読んだかを参照
- 「中村さんはこの本をこう解釈した」が資産になる
- 著者・本を超えた「知の系譜」が可視化

### ❹ 継続的な読書の動機付け

- 次に読むべき本が常に提示される
- 「読書ログ」がゲーミフィケーションされる
- バリューブックスでの購入に直結

## 4. 機能要件

### Phase 1: 読書伴走（MVP）

| 機能 | 説明 |
|------|------|
| **本の登録** | ISBNスキャン or 手入力で読書中の本を登録 |
| **文脈の設定** | 「今の仕事」「関心事」「読書の目的」を入力 |
| **写真アップロード** | 気になるページを撮影してAIに共有 |
| **AI対話** | テキストチャットで本の内容を深掘り |
| **読書ログ** | 対話履歴・インサイトの自動保存 |

### Phase 2: レコメンド強化

| 機能 | 説明 |
|------|------|
| **読書履歴分析** | 既読本から読書傾向を分析 |
| **次の本提案** | 文脈に基づくパーソナライズドレコメンド |
| **戦略的リーディングプラン** | 「どこから読むか」の提案 |
| **関連本ネットワーク** | 本と本のつながりを可視化 |

### Phase 3: ソーシャル機能

| 機能 | 説明 |
|------|------|
| **読書体験の公開** | 対話ログの一部を他ユーザーに公開 |
| **他者の読書体験閲覧** | 「この本を読んだ人の感想」を参照 |
| **フォロー機能** | 特定のユーザーの読書をフォロー |
| **読書サークル** | テーマ別の読書コミュニティ |

### Phase 4: バリューブックス統合

| 機能 | 説明 |
|------|------|
| **購入導線** | レコメンド本をワンクリックで購入 |
| **在庫連携** | バリューブックスの在庫と連動 |
| **買取連携** | 読了後の買取申込み |
| **ポイント経済圏** | 読書活動でポイント獲得 |

## 5. ユーザージャーニー

### シナリオ：経営者Aさん

```
1. [登録] Aさんがアプリをダウンロード
   - 「IPO準備中の経営者」「従業員30人」「長野在住」を入力

2. [本の登録] 『THE WEALTH LADDER』を読み始める
   - ISBNスキャンで登録

3. [伴走開始] 第3章で疑問
   - ページを写真撮影
   - 「この部分、自分の会社に当てはめるとどうなる？」

4. [AI対話]
   - AIが「従業員への株式分配」の文脈で解説
   - 「御社の場合、IPO時にこうすると良いかもしれません」

5. [インサイト保存]
   - 「従業員のレベル1→2支援が重要」がログに自動保存

6. [読了後]
   - AIが次の本を提案：「『社員をサーフィンに行かせよう』がおすすめ」
   - ワンクリックでバリューブックスから購入

7. [共有]
   - Aさんの読書体験が匿名で公開
   - 他の経営者が「経営者×資産形成」の読み方を参照
```

## 6. 技術的検討事項

### AI基盤

| 項目 | 選択肢 |
|------|--------|
| LLM | Gemini API / Claude API / OpenAI API |
| 画像認識 | OCRでテキスト抽出 → LLMで解釈 |
| ベクトルDB | 読書ログの検索・類似度計算 |

### データモデル

```
User
├── profile（文脈情報）
├── reading_history（読書履歴）
├── conversations（AI対話ログ）
└── insights（抽出されたインサイト）

Book
├── metadata（ISBN、タイトル、著者）
├── chapters（章構成）
└── user_readings（この本を読んだユーザー）

Recommendation
├── from_book（元の本）
├── to_book（推薦先の本）
├── context（なぜこの本が次に良いか）
└── user_context（ユーザーの状況）
```

### UI/UX

- モバイルファースト（読書中に使う）
- カメラ機能との連携
- 音声入力対応（ハンズフリー読書）

## 7. バリューブックスとの親和性

### なぜバリューブックスがやるべきか

1. **本の在庫データ**を持っている
   - レコメンドした本がすぐ買える

2. **買取サービス**との連携
   - 読了後の本を循環させる

3. **「本の循環」というミッション**との一致
   - 単なる売買から「読書体験の最大化」へ

4. **古本の強み**
   - 新刊より幅広いラインナップ
   - 絶版本も含めたレコメンドが可能

### 競合優位性

| 競合 | バリューブックスの差別化 |
|------|-------------------------|
| Kindle X-Ray | 購入済み本限定 → VBは全ての本に対応 |
| 読書メーター | 記録のみ → VBはAI伴走付き |
| Blinkist | 要約のみ → VBは深掘り対話 |
| Amazon | 購入導線 → VBは「読書体験全体」をデザイン |
