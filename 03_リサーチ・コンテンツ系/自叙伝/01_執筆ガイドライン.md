## 🎨 文章のデザインシステム（スタイルガイド）

### 基本方針

**文体：**
- 一人称「私」で統一
- です・ます調（敬体）は使わない
- だ・である調（常体）で書く
- ただし、会話文や引用は柔軟に

**トーン：**
- 誠実で率直
- 飾らない、カッコつけない
- 弱さや矛盾を隠さない
- でも自虐的になりすぎない

**リズム：**
- 短文と長文を織り交ぜる
- 一文一義を基本に、時々長い文で流れを作る
- 段落は短めに（3-5文程度）
- 余白を大切に（改行を恐れない）

### 文章パターン（コンポーネント）

#### パターン1: 情景描写から入る
```markdown
例：序章の冒頭

気がつけば、私たちの倉庫は巨大な「川」の合流地点のようになっていた。

毎日、4万冊。
それが、ここ長野県上田市の倉庫に流れ着く本の数だ。
```

**使いどころ：** 章の冒頭、大きな転換点

#### パターン2: 問いかけで始める
```markdown
例：第1章の冒頭

「なぜ、古本屋を始めたのですか？ 昔から本が好きだったのですか？」

インタビューや取材の場で、必ずと言っていいほど投げかけられる質問だ。
```

**使いどころ：** 読者の疑問を先回りして答える時

#### パターン3: 内面の独白
```markdown
例：第1章より

何者にもなれない自分は、これからどうすればいいのか。
```

**使いどころ：** 感情や葛藤を描く時

#### パターン4: 対比構造
```markdown
例：第5章より

躁の私が「ビジネスマン」として暴走し、鬱の私が「哲学者」としてそれを諌める。
```

**使いどころ：** 二つの要素を際立たせたい時

#### パターン5: 具体的な数字・事実
```markdown
例：序章より

残りの9冊は、どうなるか。
倉庫に置いておけば、翌日また10冊届く。翌々日も、その次の日も。
あっという間に、同じ本が何百冊、何千冊と積み上がる。
```

**使いどころ：** 実感を持たせたい時、規模感を伝えたい時

### 禁止事項

❌ **避けるべき表現：**
- 安易な比喩（特に月並みなもの）
- 説明的すぎる文章（「〜ということだ」「〜と言える」）
- ビジネス書的な抽象論
- 感情の押し付け（「感動的だった」など）

✅ **代わりにすべきこと：**
- 具体的な情景や行動で示す
- 読者に想像させる余地を残す
- 事実を積み重ねて、読者自身に結論を導かせる

## 📝 章の構成テンプレート

### 標準的な章の構造

```markdown
# 第X章：タイトル

[冒頭：読者を引き込む情景、問いかけ、または印象的なエピソード]
（200-400字）

---

[本論1：主要なエピソードや出来事]
（800-1200字）

[本論2：内面の変化や気づき]
（800-1200字）

[本論3：次の展開への伏線]
（400-800字）

---

[締め：次章への橋渡し、または余韻を残す一文]
（100-200字）
```

### 章の長さの目安

- **最小:** 2,000字（第2-3章などの短い章）
- **標準:** 2,500-3,000字（読みやすい長さ）
- **最大:** 4,000字（重要な転換点の章）

**全体:** 序章+15章+終章 = 17章 × 平均3,000字 = 約51,000字
（エピローグや補足で調整して80,000字を目指す）

## 🛠️ Cursorでの執筆支援の使い方

### AIアシスタント（私）の使い方

私は、あなたの「編集者」として機能します。

#### 1. インタビュワーとして使う
```
例：「第6章を書くために、私の本質を引き出す質問をして」
例：「今の気持ちをうまく言葉にできない。質問して引き出して」
```
**効果:** 言語化しにくい記憶や感情を引き出す
**編集者の視点:** 表面的な話に満足せず、「それ、もっと詳しく」と深掘りする

#### 2. エディターとして使う
```
例：「この段落、文章が硬い。もっと読みやすく書き直して」
例：「この章、3000字に膨らませたい。どこを膨らませればいい？」
```
**効果:** 文章の質を高める、推敲の手間を減らす
**編集者の視点:** 「削る勇気」と「膨らませる技術」の両方を提案

#### 3. 読者の代弁者として使う
```
例：「この章、読者は退屈しない？」
例：「ここ、分かりにくくない？」
```
**効果:** 客観的な視点を得る
**編集者の視点:** 作家は気づかない「読者の引っかかり」を指摘

#### 4. 構成チェッカーとして使う
```
例：「第3章と第4章の繋がりが弱い。どう橋渡しすればいい？」
例：「この伏線、回収できてる？」
```
**効果:** 全体の流れを滑らかにする
**編集者の視点:** 俯瞰して見て、山場の配置や展開の適切さを判断

#### 5. アイデア出しパートナーとして使う
```
例：「第7章で『初めて人を雇う』エピソードを書きたい。どんな視点で書けばいい？」
例：「ここにもう一つエピソードが欲しい。何がいい？」
```
**効果:** 書くべき内容の焦点を定める
**編集者の視点:** エピソード在庫から最適なものを提案

#### 6. 励ます役として使う
```
例：「今日は書けない」
例：「この章、うまく書けている？」
```
**効果:** 精神的なサポート
**編集者の視点:** 良いところを見つけて伝える、無理させない

#### 7. 検証役として使う
```
例：「今日書いた部分、全体のトーンと合っている？」
例：「この表現、他の章と矛盾してない？」
```
**効果:** 一貫性を保つ
**編集者の視点:** 文体、時系列、用語の統一をチェック

#### 8. 冷酷な判断役として使う
```
例：「この章、本当に必要？」
例：「このエピソード、削ってもいい？」
```
**効果:** 全体のために削る決断をサポート
**編集者の視点:** 良い文章でも、全体のバランスのために削ることを提案

### 並行作業の活用

Cursorでは複数ファイルを開いて作業できるので：

- **左ペイン:** 執筆中の章
- **右ペイン:** `04_エピソード在庫.md`（参照用）
- **下ペイン:** `06_編集者の視点.md`（問いかけ確認用）

**推奨する「編集会議」の進め方:**
1. まず `06_編集者の視点.md` を開く
2. 該当する章への「編集者の問いかけ」を読む
3. 思いついたことを `04_エピソード在庫.md` にメモ
4. 章を書き始める
5. 詰まったら、AIに「編集者として質問して」と頼む

## 📊 品質管理（QA）

### チェックリスト

各章を書き終えたら、以下を確認：

#### 内容面
- [ ] この章で伝えたいことは明確か？
- [ ] 前の章から自然に繋がっているか？
- [ ] 次の章への橋渡しはあるか？
- [ ] 具体的なエピソードが含まれているか？
- [ ] 抽象的な説明に終始していないか？

#### 文体面
- [ ] 常体（だ・である調）で統一されているか？
- [ ] 短文と長文のバランスは取れているか？
- [ ] 読点（、）が多すぎないか？
- [ ] 同じ語尾の連続がないか？（〜た。〜た。など）
- [ ] 不要な形容詞や副詞がないか？

#### 技術面
- [ ] 誤字脱字はないか？
- [ ] 固有名詞の表記は統一されているか？
- [ ] 時系列に矛盾はないか？
- [ ] 文字数は目安の範囲内か？

## 🔧 リファクタリング戦略

### いつリファクタリングするか

**❌ しない方がいいタイミング：**
- 執筆のモメンタムがある時
- 第一稿を書いている途中

**✅ するべきタイミング：**
- 一つの部（3-5章）を書き終えた時
- 全体の半分を書き終えた時
- 全体を書き終えた時

### リファクタリングの優先順位

1. **構造の整合性**（最優先）
   - 時系列の矛盾
   - 章の繋がり
   - テーマの一貫性

2. **文章の読みやすさ**
   - 冗長な部分の削除
   - リズムの改善
   - 分かりにくい表現の書き直し

3. **表現の洗練**
   - より良い比喩の発見
   - 印象的な言い回し
   - 余韻を残す締めくくり

## 💡 執筆のヒント

### 書けない時の対処法

1. **別の章を書く**
   - 時系列順に書く必要はない
   - 書きたい章から書く

2. **エピソードだけ箇条書きにする**
   - 完璧な文章を目指さない
   - 「骨」だけ作って後で「肉」をつける

3. **インタビュー形式で書く**
   - 誰かに話すつもりで書く
   - 後で文章に整える

4. **場所を変える**
   - 倉庫で書く
   - カフェで書く
   - 環境を変えると視点が変わる

### 文字数を増やす時の戦略

**❌ やってはいけないこと：**
- 形容詞を増やす
- 同じことを繰り返す
- 不要な説明を追加する

**✅ やるべきこと：**
- 具体的なエピソードを追加
- 感覚的な描写を増やす（音、匂い、手触り）
- 内面の葛藤を掘り下げる
- 対話を入れる

### 読者を引き込むテクニック

1. **冒頭に引っかかりを作る**
   - 意外な事実
   - 疑問形
   - 印象的な情景

2. **具体性で説得する**
   - 「たくさん」→「4万冊」
   - 「困った」→「太陽が登らないと眠れなくなった」

3. **余白を残す**
   - すべてを説明しない
   - 読者の想像に委ねる

## 🎯 成功の定義

### この本が成功したと言える時：

1. **個人的な成功:**
   - 自分の物語を正直に語れた
   - 後悔なく書ききった

2. **読者への影響:**
   - 「カッコ悪くても生きていい」と思える人が一人でも増えた
   - 矛盾を抱えることを肯定できる人が増えた
   - 古本屋や本への見方が変わった人がいた

3. **ビジネスへの影響:**
   - バリューブックスのミッションがより明確になった
   - 共感してくれる人や協力者が増えた
