  - 10畳のダイニングキッチンを作業部屋に

  - 部屋いっぱい隙間なく本棚、5,000冊超え
  - 引っ越してから3ヶ月で再び限界
  
- [x] **仲間との「隙間」生活** ✅収集済み
  - 高校時代の仲間たちが手伝ってくれるように

### 組織の形

- [ ] **「Organization as Code」という思想**
  - 組織図、戦略、タスクをコードのように管理
  - フラットなネットワーク型組織
  - 上下関係ではなく「機能」でチームを分ける

- [ ] **各チームの存在**
  - 倉庫部門、買取部門、ロジ・オペレーション
  - 自社サイト開発チーム
  - プロアカウントチーム
  - 一人で始めた事業が、これだけの組織になった

- [ ] **ファウンダーとしての関わり方**
  - 全チームに関与するが、関与の仕方はプロジェクトにより異なる
  - 「任せる」と「関わる」のバランス
  - リーダーとして直接関わる時と、クライアントとして距離を置く時

---

### 倉庫革命：SKYPOD

- [ ] **3D自動倉庫の導入**
  - 「本棚ごと運んでくるロボット」
  - 天井まで届く高い本棚
  - 作業員は動かず、必要な本が目の前に来る
  - 初期投資7,300万円

- [ ] **3つのレーンへの自動振り分け**
  - レーン1：リサイクル行き（人が見ずに自動でリサイクル）
  - レーン2：しっかり検品（高価な本、リスク高い本）
  - レーン3：そのままGO（検品なしで即入庫）
  - → 検品作業が1/4に削減

- [ ] **「そのままGOレーン」の意味**
  - ユーザーの事前申告を信じる「性善説モデル」
  - もし問題があっても低価格なのでリスク小
  - 万が一クレームが来たら、その時対応
  - → この「信じる」という選択は、本の矛盾と向き合う姿勢と通じる

## 🔮 未来のビジョン（2026-2028年）- 戦略資料より

**終章・エピローグで活用可能な素材**

### 2026-2028年の全社ゴール

- [ ] **財務目標：売上300億円（100億×3構想）**
  - 古本買取販売：100億円
  - 新刊販売：100億円
  - MD・新規事業：100億円

- [ ] **状態目標：AI時代の「人間的幸福」のリーダー**
  - デジタル、SNS、AIの依存から
  - 本を通じて人間を「アナログ」と「自然・人間同士の素晴らしさ」に引き戻す
  - → これは創業の動機（生き延びるため）から遠く離れた場所

---

### 循環型ポイント経済圏

- [ ] **「売る」と「買う」の壁を壊す**
  - 買取金額をポイントで受け取ると+10%上乗せ
  - ポイントでぐるぐる回る仕組み
  - 売った人が、また買い、また売る循環

- [ ] **ポイント限定の「レア体験」**
  - 倉庫見学ツアー（バリブツアー招待券：5,000pt）
  - 「お金じゃ買えないワクワク」を作る
  - ポイントをそのまま寄付できる（チャリボン連携）

- [ ] **循環の哲学**
  - お金が外に出ていかない
  - お客さんがずっと仲良くしてくれる
  - 「売る人」と「買う人」が別々じゃなくなる

---

### 協力型買取（本棚スキャン）

- [ ] **「ちょっとの協力」で、簡単なのに高く売れる**
  - スマホで本棚を撮影するだけ
  - AIが自動認識・価格提示
  - 状態を簡単入力すると価格UP
  - → 「協力型買取」という新ジャンルの創造

- [ ] **予測超過ボーナス**
  - 予測より高く売れたらポイント還元
  - 売った後も"良い知らせ"で接触が続く
  - → ユーザーとの関係が「一回きり」じゃなくなる

- [ ] **ユーザーを「協力者」として組み込む**
  - 従来は「お客さん」だった
  - これからは「一緒に本を救う仲間」
  - → 創業時の「一人」から「みんな」への変化

---

### プロアカウント（著者・本屋との協働）

- [ ] **「広さ」より「深さ」**
  - あちこちに広げるより、仲のいいパートナーと成功事例を作る
  - 著者が自分の本を直販できる
  - 本屋がオンラインでも売れる

- [ ] **収益配分の革新**
  - 一般書店：著者取り分10%
  - Amazon：著者取り分35%
  - バリブ・プロアカウント：著者取り分**70%**
  - → 「本を書く人」がもっと報われる世界

- [ ] **エコシステムの構築**
  - 著者、出版社、本屋、読者がつながる
  - みんなが「バリブと組むといいことある」
  - → 「古本屋」じゃない、新しい価値

---

### メディア展開

- [ ] **YouTube「積読チャンネル」**
  - 強力なファンコミュニティ
  - 本好きへのリーチ
  - 月間500万回再生を目標

- [ ] **Video Podcast（新しい試み）**
  - 著者に密着
  - ファンが応援買い
  - → 本を売るだけじゃない「体験」を作る
