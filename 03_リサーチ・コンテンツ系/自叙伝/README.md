## 📚 目次

### 📖 第一部：漂流

#### [序章：本の還る場所](序章_本の還る場所.md)
毎日4万冊が流れ着き、2万冊が古紙回収へ向かう倉庫。コンテナの前に立ち、「値段がつかない」ことと「価値がない」ことの違いを問う。

#### [第1章：漂流と均衡](第1章_漂流と均衡.md)
「なぜ、古本屋を？」という問いへの答え。就職せず、様々な試みに失敗し、引きこもり状態に至るまでの漂流の日々。

#### [第2章：書棚の片隅の救済](第2章_書棚の片隅の救済.md)
ジュンク堂書店での日々。偉人たちの伝記に圧倒されながら、書棚の片隅にあった「カッコ悪い実用書」に救われる。

#### [第3章：夜明けと蜘蛛の糸](第3章_夜明けと蜘蛛の糸.md)
アフィリエイトの失敗を経て、Amazonマーケットプレイスとの出会い。初めて本が売れた朝、降りてきた一本の蜘蛛の糸。

#### [第4章：最初の出荷、最初の仕入れ](第4章_最初の出荷、最初の仕入れ.md)
初めての発送作業。ブックオフでの仕入れ。部屋を埋め尽くす本の山は、人生が再び動き出した証だった。

#### [第5章：熱病と静寂のサイクル](第5章_熱病と静寂のサイクル.md)
双極性障害という診断名を知る前から、躁と鬱のサイクルに翻弄される日々。乱暴な拡大と深い内省の繰り返しの中で。

## 🎯 プロジェクト概要

### コンセプト
「生き延びるために始めたカッコ悪いビジネスが、いつの間にか『矛盾』と向き合わざるを得ない場所へと自分を連れていった」

### 核心テーマ
1. 個人の生存の物語（何者にもなれない自分が、なんとか生きる）
2. 矛盾への直視の物語（本を救おうとして、半分を捨てている）
3. 双極性障害との共生（躁鬱の波が、拡大と内省を生んだ）

### 目標文字数
- **総文字数:** 80,000字
- **章数:** 序章 + 15章 + 終章 = 17章
- **平均:** 約4,700字/章

### 執筆アプローチ
**システム開発 × 優秀な編集者** のハイブリッド執筆環境

**システム開発の構造:**
- 設計ドキュメントで方向性を定義
- スタイルガイドで文体を統一
- バックログでエピソードを管理
- 継続的なリファクタリング

**編集者の視点:**
- 対話を通じて本質を引き出す
- 読者の代弁者として客観性を保つ
- 構成と山場を俯瞰的に見る
- 削る勇気と膨らませる技術
- 励まし、支え、一緒に作る

## 💻 Cursorでの執筆について

このプロジェクトは、Cursor（AIコーディングエディタ）を使用して執筆しています。

### AIアシスタント = あなたの編集者

私（AIアシスタント）は、この本の**編集者**として機能します。

**8つの役割:**
1. **インタビュワー**: 本質を引き出す質問をする
2. **エディター**: 文章の推敲と改善
3. **読者の代弁者**: 「ここ、分かりにくい」と率直に言う
4. **構成チェッカー**: 章同士の繋がりの確認
5. **アイデア出しパートナー**: 書くべき視点の提案
6. **励ます役**: 書けない時の精神的サポート
7. **検証役**: 全体のトーンの一貫性チェック
8. **冷酷な判断役**: 「この章、本当に必要？」と聞く

**最重要:** でも、最終的にはあなたの本です。私の提案は「案」。決めるのはあなた。
