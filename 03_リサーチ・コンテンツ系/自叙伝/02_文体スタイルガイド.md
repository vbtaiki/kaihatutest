# 文体スタイルガイド - バリューブックス創業記

**この本の「声」を定義する**

---

## 🎨 基本原則

### 1. 誠実であること
- 飾らない
- カッコつけない
- 弱さや失敗を隠さない
- でも自虐的になりすぎない

### 2. 具体的であること
- 抽象的な説明より、具体的なエピソード
- 「困った」より「太陽が登らないと眠れなくなった」
- 数字や固有名詞を使う

### 3. 読者を信頼すること
- すべてを説明しない
- 余白を残す
- 読者の想像力に委ねる

---

## ✍️ 文体の基本ルール

### 文末表現

**基本：** 常体（だ・である調）で統一

```
✅ 良い例：
「それは、私にとって大きな転換点だった。」
「けれど、答えは見つからなかった。」

❌ 悪い例（敬体との混在）：
「それは大きな転換点でした。」
「けれど、答えは見つかりませんでした。」
```

**例外：**
- 会話文は自由（「〜ですか？」など）
- 引用は元の文体を尊重

### 文の長さ

**リズムを作る：** 短文と長文を織り交ぜる

```
✅ 良い例（リズムがある）：
「毎日、4万冊。
それが、ここ長野県上田市の倉庫に流れ着く本の数だ。
朝、シャッターが開くと同時に、トラックが満載の段ボールを吐き出していく。」

❌ 悪い例（単調）：
「毎日4万冊の本が長野県上田市の倉庫に流れ着く。
朝にシャッターが開くとトラックが段ボールを吐き出していく。」
```

### 段落の長さ

**基本：** 3-5文程度で一段落

```
✅ 良い例：
「布団の中でボーッとしている時間が半分。
本を読んだり、動画を見たりできる時間が半分。

最初は、まだ希望に満ちていた。「次は何をやろうか」と考える余裕もあった。
けれど、だんだんと体が鉛のようになっていく感覚があった。」

❌ 悪い例（長すぎる）：
「布団の中でボーッとしている時間が半分で、本を読んだり動画を見たりできる時間が半分だった。最初はまだ希望に満ちていて次は何をやろうかと考える余裕もあったけれど、だんだんと体が鉛のようになっていく感覚があった。」
```

## 📐 表現のパターン集

### パターン1: 数字で実感を持たせる

```
✅ 良い例：
「毎日、4万冊」
「残りの9冊は、どうなるか」
「5時間もの時間を過ごした」

❌ 悪い例：
「たくさんの本」
「残りの本は、どうなるか」
「長い時間を過ごした」
```

### パターン2: 一行で印象を残す

```
✅ 良い例：
「毎日、4万冊。」
「躁の季節がやってきたのだ。」
「地に足がついた感覚がなかった。」

❌ 悪い例：
「毎日4万冊の本が届いていた。」
「躁の状態になった。」
「地に足がついていないようだった。」
```

### パターン3: 対比で際立たせる

```
✅ 良い例：
「昨日まで『宝の山』に見えていた本の山が、突然、ただの『死骸』の集積に見えてくる。」

「躁の私が『ビジネスマン』として暴走し、鬱の私が『哲学者』としてそれを諌める。」

❌ 悪い例：
「本の山の見え方が変わった。」
「気分によって行動が変わる。」
```

### パターン4: 問いかけで引き込む

```
✅ 良い例：
「なぜ、これほどの本が捨てられなければならないのか。
『値段がつかない』とは、本当に『価値がない』ということなのか。」

❌ 悪い例：
「多くの本が捨てられている理由を考えた。
値段と価値の関係についても考えた。」
```

### パターン5: 感覚的描写

```
✅ 良い例：
「ドスン、という鈍い音。バサリ、と頁が開く乾いた音。」
「体が鉛のようになっていく感覚」
「部屋を圧迫する紙の束。埃っぽい匂い。」

❌ 悪い例：
「本が落ちる音がした。」
「体が重く感じた。」
「部屋には本がたくさんあった。」
```

## 🚫 避けるべき表現

### 1. 月並みな比喩

```
❌ 避ける：
「光が見えた」
「心が晴れた」
「新しい扉が開いた」

✅ 代わりに：
具体的な情景や行動で示す
「細く光る一本の蜘蛛の糸が降りてきたような感覚」
```

### 2. 説明的すぎる文章

```
❌ 避ける：
「これは私にとって大きな転機となったということだ」
「この経験から学んだことは〜と言える」

✅ 代わりに：
事実を提示して、読者に判断させる
「それは、バリューブックスという長い旅が、静かに、しかし確実に始まった瞬間だった。」
```

### 3. 過度な感情表現

```
❌ 避ける：
「とても感動的だった」
「非常に嬉しかった」
「すごく辛かった」

✅ 代わりに：
行動や身体感覚で示す
「震えるような安堵を感じていた」
「膝を抱えて動けなくなる」
```

### 4. ビジネス書的な抽象論

```
❌ 避ける：
「顧客ニーズに応える」
「コアコンピタンス」
「シナジー効果」

✅ 代わりに：
具体的な行動や出来事
「画面の向こうにいる誰かが、私が持っていた本を必要としてくれた」
```

## 📚 参考にすべき文章

### 自分の文章から学ぶ

**うまくいっている部分：**

1. 序章の冒頭
```
「気がつけば、私たちの倉庫は巨大な『川』の合流地点のようになっていた。

毎日、4万冊。
それが、ここ長野県上田市の倉庫に流れ着く本の数だ。」
```
→ **なぜ良い？** 短文のリズム、具体的な数字、比喩が独特

2. 第1章の就活への葛藤
```
「面接は嫌だ。
落ちたくもない。
でも、受かりたくもない。」
```
→ **なぜ良い？** 矛盾を率直に表現、短文の連打で感情を伝える

3. 第3章の蜘蛛の糸
```
「その瞬間、暗闇の底にうずくまっていた私の頭上に、細く光る一本の蜘蛛の糸が降りてきたような感覚に襲われた。」
```
→ **なぜ良い？** ありふれた「光が見えた」を避け、芥川の蜘蛛の糸を引用しつつ独自の表現に

## ✏️ 推敲のチェックポイント

### レベル1: 基本チェック（必須）

- [ ] 文末は常体で統一されているか
- [ ] 誤字脱字はないか
- [ ] 同じ語尾が3回以上連続していないか
- [ ] 一文が長すぎないか（目安：60字以内）

### レベル2: 読みやすさチェック

- [ ] 読点（、）が多すぎないか（一文に3つまでが目安）
- [ ] 段落は適切な長さか（3-5文程度）
- [ ] リズムは単調でないか
- [ ] 主語と述語は明確か

### レベル3: 表現のチェック

- [ ] 抽象的な説明に終始していないか
- [ ] 具体的なエピソードや描写があるか
- [ ] 月並みな比喩を使っていないか
- [ ] 感情の押し付けになっていないか

### レベル4: 全体のチェック

- [ ] この章で伝えたいことは明確か
- [ ] 前の章から自然に繋がっているか
- [ ] 次の章への橋渡しはあるか
- [ ] この本全体のトーンと合っているか

## 🎯 各章の「声」のバリエーション

### 序章・終章: 沈着・内省的
- トーン: 落ち着いている、深く考えている
- リズム: ゆっくり、丁寧
- 視点: 俯瞰的

### 第1-5章: 不安定・切実
- トーン: 焦燥感、切迫感
- リズム: 時に速く、時に止まる
- 視点: 近接的、主観的

### 第6-9章: 混乱・葛藤
- トーン: 迷い、矛盾
- リズム: 波のように上下する
- 視点: 内と外を行き来

### 第10-12章: 決意・責任
- トーン: 覚悟、諦観、希望
- リズム: 着実、でも完璧ではない
- 視点: 他者を意識しつつ自分も見つめる

## 💡 実践例：Before → After

### 例1: 説明的 → 具体的に

**Before:**
「その時の私は非常に嬉しかった。初めて成功したという実感があった。」

**After:**
「朝の光の中で、私は震えるような安堵を感じていた。」

### 例2: 抽象的 → 具体的に

**Before:**
「大量の本が届いて、捨てる本も多かった。」

**After:**
「毎日10冊以上届く。売れていくのはせいぜい1冊だ。残りの9冊は、どうなるか。」

### 例3: 月並み → 独自の表現に

**Before:**
「希望の光が見えた気がした。」

**After:**
「細く光る一本の蜘蛛の糸が降りてきたような感覚に襲われた。」

### 例4: 冗長 → 簡潔に

**Before:**
「当時の私は、自分の人生をどうやって生きていけばいいのかということについて、毎日のように悩み続けていた。」

**After:**
「部屋の隅で、私は自分自身に問いかけ続けていた。何者にもなれない自分は、これからどうすればいいのか、と。」

## 📖 参考文献（文体の参考）

### 学ぶべき著者たち

1. **沢木耕太郎**（『深夜特急』など）
   - 具体的な描写
   - 淡々としているが感情が滲む
   - 過度に説明しない

2. **坂口恭平**（『独立国家のつくりかた』など）
   - 率直で飾らない
   - 弱さを隠さない
   - リズムがある

3. **イヴォン・シュイナード**（『社員をサーフィンに行かせよう』）
   - ビジネス書だが説教臭くない
   - 矛盾を認める誠実さ
   - 具体例で語る

4. **梨木香歩**（『家守綺譚』など）
   - 余白の使い方
   - 言葉の選び方
   - 静かな力強さ
