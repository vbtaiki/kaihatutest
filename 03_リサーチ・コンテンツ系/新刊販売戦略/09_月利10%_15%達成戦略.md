```
現状の営業利益率：4.4%

必要な改善幅：+5.6%
月商4.2億円 × 5.6% = 毎月約2,350万円の利益改善が必要
```

| レバー | 現状 | 目標 | 改善幅 | 月間インパクト |
|--------|------|------|--------|-------------|

## ① Amazon手数料の削減（最大のレバー）

### 施策：チャネルシフトによる手数料構造の転換

| チャネル | 1月構成比 | 目標構成比 | 手数料率 |
|---------|----------|-----------|---------|
| Amazon | 63.1% | **45%** | 約15% |
| 楽天 | 18.5% | **25%** | 約8% |
| 自社サイト | 10.6% | **15%** | **約3%** |
| メルカリ等 | 5.7% | **10%** | 約10% |
| その他 | 2.1% | **5%** | 低い |

### 手数料削減の仕組み

```
Amazon構成比 63% → 45%に下げるだけで、
月間Amazon手数料：6,268万円 → 約4,000万円
→ 毎月約2,270万円の手数料削減 → そのまま利益に
```

### 具体的な施策

1. **Amazon価格の維持（10%高く設定）**
   - 高くても買う層には売れる → 1件あたりの粗利UP
   - 「高い」と感じた層は自社・楽天へ流入

2. **自社サイトへの誘導強化**
   - 「Amazon店より自社店は常に5〜10%安い」をユーザーに学習させる
   - 手数料が最も低い（決済手数料3%のみ）

3. **Amazonを「ショーケース」として活用**
   - 価格比較の起点 → 他チャネルの「お買い得感」を演出

## ② 運賃の最適化

### 施策：同梱率の向上と配送種別の最適化

**自社倉庫発送の強み**を最大限活かす。

| 施策 | 詳細 | インパクト |
|------|------|-----------|
| **同梱率の向上** | 1注文あたり1.2冊 → 1.5冊 → 2.0冊 | 発送件数の削減 |
| **配送種別の最適化** | 「厚み3cmの壁」を死守、ポスト投函便を最大化 | 1件あたり数百円削減 |
| **新刊+中古の同梱** | 同一顧客の新刊と中古を1梱包で発送 | 送料が1回分で済む |
| **低単価・厚物のAmazon排除** | 送料・手数料負けする商品はAmazon出品停止 | 赤字発送の排除 |

### 同梱による利益改善の例

```
1冊発送：利益 100円
2冊同梱：利益 100円×2 + 浮いた送料200円 = 合計400円

→ 同梱率が1.2冊→2.0冊に向上すると、
   運賃比率：13.6% → 約11%（▲2.6%）
```

> 他モール・自社発送なら、「送料浮き」がまるごと利益になる。
> Amazonではこの恩恵を受けられない。

## ③ 広告費（買取効率）の改善

### 施策：チラシ経由買取のROI管理

| 現状の構造 | 金額 |
|-----------|------|
| 月間買取仕入 | 7,545万円 |
| 月間チラシ広告費 | 約3,300万円 |
| 買取1件あたりの中古売上貢献 | 13,700円 |

### 具体的な施策

1. **チラシの反応率が低いエリアの絞り込み**
   - 獲得単価が合わないエリアは勇気を持って停止
   - 効率の良いエリアに集中

2. **新刊購入者からの買取誘導**（→ 04_買取誘導_CPA分析.md）
   - CPA 1,143円で高品質な買取客を獲得
   - 従来のCPA 3,000円から大幅改善

3. **YouTube（積読チャンネル）からの自然流入**
   - 広告費ゼロの買取・購入動線
   - 詳細は 11_積読チャンネル_YouTube戦略.md

## 🏆 月利15%を達成している状態

### 15%達成時のPLイメージ

| 項目 | 1月（4.4%） | 10%達成時 | **15%達成時** |
|------|------------|----------|-------------|
| 売上高 | 100% | 100% | 100% |
| 売上原価 | 27.0% | 25.0% | **24.0%** |
| 荷造運賃 | 13.6% | 11.5% | **8.0%** |
| 手数料 | 17.7% | 14.5% | **7.0%** |
| 広告費 | 12.0% | 10.5% | **10.0%** |
| 人件費 | 18.5% | 18.0% | **18.0%** |
| その他 | 6.9% | 10.5% | **18.0%** |
| **営業利益** | **4.4%** | **10.0%** | **15.0%** |

### 15%のとき何が起こっているか

1. **Amazon比率が30%以下に低下**
   - 「高くても買う層」専用チャネルとして割り切り
   - 月間Amazon手数料が3,000万円以下に

2. **同梱率が2.0冊以上に向上**
   - 在庫ダムの厚みでユーザーが「ついで買い」しやすい
   - 発送件数が減っても販売冊数は維持

3. **廃棄がほぼゼロ**
   - 全ての在庫がデータと物理の両面で収益化

4. **買取チラシが「超高効率な仕入装置」に変貌**
   - 「他で高く売る力（出口）」が強いため、高値で買い取っても利益が出る
   - 市場の「いい本」がバリューブックスに集中
