# 買取誘導・CPA分析

**新刊販売を「最強の仕入れマシン」に変える戦略**

---

## 📋 現状の課題

### 従来の買取獲得モデル

```
広告費（CPA 3,000円）
    ↓
買取1件獲得
    ↓
中古本売上（平均13,700円/件）
```

**問題点**：
- CPA 3,000円は高コスト
- 買取の「質」がコントロールできない（古い本も多い）
- 広告費が利益を圧迫

---

## 💡 新刊販売による買取誘導の革命

### 新しいモデル

```
新刊販売（利益を出しながら）
    ↓
チラシ同梱（コスト8円）
    ↓
買取誘導（反応率0.7%）
    ↓
優良な中古在庫を獲得
```

**メリット**：
- 広告費が「利益」に変わる
- 買取の「質」が劇的に向上（発売直後の新刊＝高価値）
- CPAが大幅に低減

---

## 📊 CPA比較シミュレーション

### 従来モデル vs 新刊モデル

| 項目 | 従来（広告） | 新刊販売モデル |
|------|-------------|---------------|
| **コスト/件** | 3,000円 | **1,143円** |

## 🔢 詳細計算

### 前提条件

| 項目 | 数値 |
|------|------|
| 1日の新刊販売数 | 5,000冊 |
| チラシ1枚のコスト | 8円 |
| 買取への反応率 | 0.7% |
| 新刊1冊あたりの利益 | 140円（70%仕入れ） |
| 買取1件の中古売上貢献 | 13,700円 |

### 1日あたりの効果

| 項目 | 計算 | 金額 |
|------|------|------|
| 新刊販売利益 | 5,000冊 × 140円 | 700,000円 |
| チラシコスト | 5,000枚 × 8円 | ▲40,000円 |
| **新刊からの純利益** | | **660,000円** |
| 買取成約数 | 5,000 × 0.7% | 35件 |
| **買取CPA** | 40,000円 ÷ 35件 | **1,143円** |

### 従来広告で同じ35件を獲得する場合

| 項目 | 計算 | 金額 |
|------|------|------|
| 広告費 | 35件 × 3,000円 | ▲105,000円 |

**新刊モデルとの差額**：660,000円 ＋ 105,000円 ＝ **765,000円/日の改善**

## 🎯 なぜ新刊購入者は「良い買取客」なのか

### 1. 在庫の「鮮度」が高い

| 買取経路 | 在庫の特徴 |
|---------|-----------|
| 従来の広告経由 | 古い本も多い、状態がばらつく |
| **新刊購入者** | **発売直後の本、状態が良い** |

新刊購入者が売る本は：
- 発売から数週間〜数ヶ月
- 中古販売価格が定価の70〜80%
- 検品コストが低い

### 2. 「ついで買取」の発生

新刊を1冊買った人は、他にも本を持っている可能性が高い。

```
新刊1冊購入
    ↓
チラシを見る「ついでに他の本も売ろう」
    ↓
1回の買取で複数冊送付
    ↓
1件あたりの売上貢献が大幅増
```

### 3. リピーターへの転換

```
新刊購入 → 買取体験 → 満足 → リピート購入 → また買取
                         ↑                   ↓
                         └───────────────────┘
```

**2回目以降の買取獲得コストはゼロ**。

## 📦 チラシ設計のポイント

### 同梱するチラシの要素

1. **即時性のあるオファー**
   - 「今なら〇〇円で買取」
   - 購入した本のリアルタイム買取価格を表示

2. **シームレスな体験**
   - QRコードで即査定
   - スマホで撮影 → 買取価格表示 → 申込

3. **心理的インセンティブ**
   - 「読み終わったら売る」という習慣化
   - 「実質レンタル」感覚の提案

### チラシ例

```
┌─────────────────────────────────────────┐
│  📚 読み終わったら、すぐ売れる！       │
│                                         │
│  ▼ 今お買い上げの本                    │

│                                         │
│  🏷️ 買取価格：¥1,050（定価の70%）     │
│                                         │
│  📱 このQRコードで今すぐ査定            │
```

反応率が1.5%になった場合：
- **CPA：40,000円 ÷ 75件 ＝ 533円**

## 💰 収益構造の変化

### Before（従来モデル）

```
広告費 3,000円 → 買取1件 → 中古売上 13,700円
                         → 粗利 約5,000円
                         → 純利益 約2,000円

広告費込みの純利益：2,000円 - 3,000円 = ▲1,000円（赤字）
```

※ 実際は複数回の取引で回収するが、1件あたりは赤字。

### After（新刊モデル）

```
新刊販売 1,500円 → 利益 140円
    ↓
買取誘導 → 買取1件 → 中古売上 13,700円
                    → 粗利 約5,000円
                    → 純利益 約2,000円

新刊利益 + 買取純利益 = 140円 + 2,000円 = +2,140円/サイクル
```

**1サイクル（新刊販売→買取→中古販売）で2,140円の純利益**
