## 🚀 3ステップ計画（→ [06_実行計画.md](./06_実行計画.md) に詳細）

### Step 1：仕入れ＆販売テスト（2026年3月〜10月）

日販等から**1億円分の売れ筋を一括仕入れ**。
自社ユーザーへのレコメンド、楽天・メルカリでの販売テストで「何が売れるか」を徹底検証。

### Step 2：SKYPOD稼働 × 直取引60%攻勢（2026年11月〜）

**11月のSKYPOD稼働で空いたスペース**を新刊在庫に充て、出版社に**掛率60%の直取引**を一斉提案。

出版社に提示する条件：
- まとめ仕入れ（新倉庫のスペースに）
- 物流代行（出版社の指示でどこにでも発送）
- **著者還元（書店取り分の30%を著者に返す）**
- 販売努力（自社ユーザー・プロアカウント書店・積読チャンネル）
- お試しOK

**5万タイトル**を60%で確保することを目指す。

### Step 3：循環エコシステムの完成（2027年後半〜）

3つの循環を同時に回す：
1. **ポイント買取 → 新刊購入**：買取金額をポイントで受け取り、新刊を買う
2. **積読チャンネル × 著者タイアップ**：有力著者の新刊を「発射台」として紹介、著者に利益を還元
3. **プロアカウント書店への新刊卸売**：60%仕入れの本を書店に80-85%で卸売 → 在庫回転の加速
