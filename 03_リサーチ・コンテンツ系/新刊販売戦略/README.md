# 📚 新刊販売戦略 - VALUE BOOKS

**「新刊販売を仕入れエンジンに変える」循環型書店モデル**

---

## 🎯 戦略の概要

バリューブックスの強み（**送料100円の物流コスト**）を活かし、新刊販売を以下の目的で展開する：

1. **自社サイト・楽天・メルカリ等での新刊販売**
2. **プロアカウント経由での書店への卸売**
3. **販売実績を通じた出版社との直取引交渉**
4. **新刊購入者への買取誘導による優良中古在庫の確保**

## 💡 なぜ今、新刊販売なのか？

### 従来の古本屋モデルの限界

```
広告費（CPA 3,000円）→ 買取獲得 → 中古販売
                    ↑
              コストが高騰
```

### 新刊販売による革命

```
新刊販売（利益を出しながら）→ チラシで買取誘導 → 中古販売
            ↑                         ↓
      出版社との交渉力UP        優良在庫の自動確保
            ↑                         ↓
        実績蓄積 ← ← ← ← ← ← ← 循環
```

## 🔑 成功の鍵

### 1. 仕入れ条件の改善

| ルート | 仕切率 | 判定 |
|--------|--------|------|
| 日販（取次） | 78% | 赤字〜トントン |
| トランスビュー等 | 70% | **主力として成立** |
| 出版社直取引 | 60% | **高収益** |

### 2. バリューブックスの武器

- **送料100円**：ブックファンに匹敵する物流コスト
- **新刊+中古の同梱**：1件あたり利益の最大化
- **買取誘導の循環**：競合には真似できない「売って買う」サイクル

---

## 🚀 次のステップ

1. **ジャンル選定**：バリューブックスが強い分野（ビジネス、IT、デザイン等）から開始
2. **仕入れ先確保**：トランスビュー・子どもの文化普及協会との取引開始
3. **楽天出店準備**：新刊専用ショップまたは既存ショップへの統合
4. **チラシ設計**：買取誘導率を高めるクリエイティブ開発
