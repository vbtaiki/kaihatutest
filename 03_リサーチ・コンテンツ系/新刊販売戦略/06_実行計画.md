## 🧪 Step 1：仕入れ＆販売テスト（2026年3月〜10月）

### 目的

**「新刊をちゃんと仕入れたら、バリューブックスで売れるのか？」を検証する**

Step 2の直取引交渉の前に、「バリューブックスは新刊を売る力がある」というデータと実績を作る。

### 初期仕入れ

| 項目 | 内容 |
|------|------|
| 仕入れ予算 | **約1億円**（初期在庫として一括） |
| 仕入れ先 | **日販（78%・返品可）＋ 子どもの文化普及協会（70%・買い切り）** |
| 対象 | **売れ筋の本を幅広く** → ジャンルを絞らず「何が動くか」を見る |
| 仕入れの考え方 | 利益を出すためではなく、**市場テスト** |
| 仕入れ判定 | → **[12_新刊仕入れシステム設計.md](./12_新刊仕入れシステム設計.md)** で自動振り分け |

> **仕入れ先の使い分け：**
> - **ロングセラー**（古本市場でも人気・価格安定）→ **子どもの文化（70%・買い切り）** で高利益
> - **トレンド本**（話題だが売れ残りリスクあり）→ **日販（78%・返品可能）** でリスクヘッジ
> - VBの古本データベースを使って、AIが自動で振り分ける

> 子どもの文化（70%買い切り）なら利益が出るが、売れ残りは丸損。
> 日販（78%返品可）なら利益は薄いが、売れなければ返品できる。
> **VBの古本データを使い、「確実に売れる本は買い切り、不確実なものは委託」と自動判定する。**

### 販売テストの項目

| テスト項目 | 検証すること |
|-----------|-------------|
| **自社ユーザーへのレコメンド** | 既存の買取・購入ユーザーに新刊をおすすめしたら買うか？ |
| **楽天での販売** | 楽天ユーザーはバリューブックスで新刊を買うか？ |
| **メルカリでの販売** | 中古と並べて新刊を出したら動くか？ |
| **ジャンル別の反応** | ビジネス書？文芸？人文？絵本？何が強いか？ |
| **価格帯別の反応** | 高単価（2,000円以上）と低単価（1,000円以下）のどちらが動くか？ |
| **積読チャンネルとの連動** | 動画で紹介した本は、在庫があればどこまで売れるか？ |
| **買取誘導チラシの効果** | 新刊購入者にチラシを入れたら、買取に反応するか？ |

### Step 1のKPI

| 指標 | 3ヶ月後 | 6ヶ月後 | 8ヶ月後（Step 2直前） |
|------|---------|---------|---------------------|
| 販売冊数/月 | 3,000冊 | 8,000冊 | 15,000冊 |
| 月間売上 | 500万円 | 1,200万円 | 2,500万円 |
| 在庫アイテム数 | 5,000 | 10,000 | 20,000 |
| 販路別の売上構成比 | 把握 | 最適化中 | 確立 |
| 買取チラシ反応率 | 測定開始 | 0.5% | 0.7% |

### Step 1で手に入れるもの

1. **「何が売れるか」のデータ** → Step 2の出版社交渉の武器に
2. **「バリューブックスで新刊が買える」という認知** → 既存ユーザーの習慣づけ
3. **オペレーションの確立** → 新刊のピッキング・梱包・発送フローの完成
4. **販路別の最適解** → どこで何を出せば最も効率が良いか

## 🚀 Step 2：SKYPOD稼働 × 直取引60%攻勢（2026年11月〜）

### 背景：なぜ11月なのか？

**2026年11月にSKYPOD（自動倉庫システム）が稼働**し、既存の棚スペースが大幅に空く。
このタイミングが、新刊在庫を一気に拡大し、出版社との直取引交渉を攻めに行く絶好の機会。

### 出版社への営業ピッチ

> **「掛率60%でバリューブックスに卸してくれませんか？」**

#### 提示する条件

| 条件 | 内容 |
|------|------|
| **① 掛率** | **60%**（通常の書店は78%で仕入れているところを、大幅に優遇してもらう） |
| **② まとめ仕入れ** | 新倉庫稼働のタイミングなので、まとめてある程度の量を仕入れる |
| **③ 物流代行** | 出版社の指示で、さまざまな場所への発送も行う（3PL機能） |
| **④ 著者還元** | 著者などの発信で売れた場合は、**書店取り分のうち30%を著者に返す** |
| **⑤ 販売努力** | 自社ユーザー、プロアカウント書店、積読チャンネルのリスナーに売る努力をする |
| **⑥ お試しOK** | まずは試しにこの条件でチャンスをください |

### 営業ピッチの具体トーク

```
「バリューブックスは年間40億円の売上を持つ日本最大級のネット古書店です。
 
 現在、自社に30万人以上のユーザーがいて、
 YouTubeの積読チャンネルでは1タイトル数百冊を動かす力があります。
 
 11月に新しい自動倉庫（SKYPOD）が稼働し、
 大量の新刊在庫を保管できるスペースが生まれます。

 ぜひ、掛率60%で御社の本を仕入れさせてください。
 
 バリューブックスが提供できること：
 ・自社ユーザー30万人への販売
 ・楽天・メルカリ等のモールでの販売
 ・プロアカウント（登録書店）への卸売
 ・YouTubeでの紹介による販促
 ・著者の発信で売れた分は、書店取り分の30%を著者に還元
 ・御社の指示に応じた物流代行（各所への発送）
 
 まずはお試しでも構いません。
 この条件でチャンスをいただけないでしょうか？」
```

### 営業のターゲット

#### 優先度A：積読チャンネルで実績のある出版社（→ 11_積読チャンネル_YouTube戦略.md 参照）

すでに取引実績・担当者の連絡先がある約30社。
「実際にこれだけ売りました」とデータを見せて交渉できる最強のリスト。

| 出版社 | 実績タイトル例 | 累計販売数 |
|--------|-------------|----------|
| 早川書房 | 息吹、あなたの人生の物語、精密への果てなき道 等 | 1,000冊以上 |
| 講談社 | 叙述トリック短編集、ハロー・ワールド 等 | 800冊以上 |
| 毎日新聞出版 | ある行旅死亡人の物語、政治学者PTA会長 等 | 1,100冊以上 |
| 青土社 | なぜ私たちは燃え尽きてしまうのか | 637冊 |
| 左右社 | 医学問答 | 617冊 |
| プレジデント社 | 最高の集い方 | 311冊 |
| 築地書館 | 計測の科学 | 300冊 |
| 日経BP | 教養としてのCS講義 | 269冊 |

#### 優先度B：バリューブックスと相性の良い出版社

人文・社会科学・ノンフィクション系の中小出版社から攻める。

#### 優先度C：大手出版社

実績を積んでから段階的にアプローチ。

### Step 2の目標

| 指標 | 11月時点 | 2027年3月 | 2027年6月 |
|------|---------|----------|----------|
| 直取引出版社数 | 10社 | 30社 | **50社以上** |
| 直取引60%のタイトル数 | 5,000 | 20,000 | **50,000** |
| 新刊月間売上 | 5,000万円 | 1億円 | **1.5億円** |
| 新刊在庫規模 | 3億円 | 5億円 | 8億円 |

### 著者還元モデルの設計

```
定価1,500円の本が「著者の発信」で売れた場合：

出版社への支払い：1,500円 × 60% = 900円
バリューブックスの取り分：600円
    ↓
うち30%を著者に還元：600円 × 30% = 180円（定価の12%）
バリューブックスの残り：600円 × 70% = 420円
    ↓
変動費（送料100円＋手数料等）を引いても：+110〜210円の利益
```

> 著者は通常の印税（定価の10%＝150円）に加え、
> 自分の発信で売れた分にはさらに180円が入る。
> **「バリューブックスで買ってほしい」と言うインセンティブが生まれる。**

## 🔄 Step 3：循環エコシステムの完成（2027年後半〜）

### 3つの循環を同時に回す

#### 循環①：ポイント買取 → 新刊購入

```
ユーザーが不要な本を買取に出す
    ↓
買取金額を「ポイント」で受け取る（キャッシュアウトなし）
    ↓
そのポイントで新刊（60%仕入れ）を定価で購入
    ↓
バリューブックスは：
  ・ポイント = 自社通貨で仕入れ → 実質キャッシュアウトゼロ
  ・新刊は粗利40%（60%仕入れ）で販売
    ↓
ユーザーが読了後、またポイント買取へ → 循環
```

#### 循環②：積読チャンネル × 著者タイアップ

```
有力な著者の新刊発売
    ↓
積読チャンネルで「発射台」として紹介
    ↓
バリューブックスの自社サイトで先行販売（著者サイン入り等）
    ↓
著者には書店取り分の30%を還元
    ↓
著者が「バリューブックスで買ってください」とSNSで発信
    ↓
大量の読書家ユーザーがバリューブックスに流入
    ↓
その読者が次の本も買い、買取も利用する → 循環
```

#### 循環③：プロアカウント書店への新刊卸売

```
バリューブックスが60%で大量仕入れ
    ↓
プロアカウント登録の書店に80〜85%で卸売
    ↓
書店は取次（78%）より安く仕入れられる
    ↓
バリューブックスの新刊在庫がさらに回転
    ↓
出版社に「これだけ売れた」と実績を積む
    ↓
さらに多くのタイトルを60%で仕入れ → 循環
```

## ⚠️ リスクと対策

### リスク1：出版社が60%の掛率を受け入れない

**対策：**
- Step 1の販売データを武器に「これだけ売れた」と実証
- 最初は「お試し」で少量からスタート、実績を作って拡大
- 著者還元モデル（30%）が他の書店にない独自価値として刺さる
- 物流代行（3PL）サービスをセットで提案 → 出版社のコスト削減になる

### リスク2：売れ筋を仕入れても売れない

**対策：**
- Step 1はテスト期間と割り切り、何が動くかのデータ収集に徹する
- 複数販路（自社・楽天・メルカリ）で在庫を分散
- 積読チャンネルでの紹介と連動して在庫を動かす
- 中古と新刊のセット販売で差別化

### リスク3：在庫が膨らんでキャッシュが圧迫される

**対策：**
- Step 2でのまとめ仕入れは、SKYPOD稼働後のスペース内に収める
- 回転しないタイトルは早めにプロアカウント書店へ卸売で消化
- 日販の返品条件を活用し、初期はリスクを最小限に

### リスク4：ブックファンとの競合

**対策：**
- 価格競争はしない（60%仕入れなら利益を保てる）
- 「新刊+中古の同梱」「ポイント買取」「著者還元」で差別化
- ブックファンにない「売ったら次の本が買える循環モデル」が最大の強み
