# ダム戦略：脱Amazon × 在庫の厚み

**「いい本のダムを作り、Amazonをフィルターに変える」**

---

## 📋 戦略の背景

### 2月に始めた施策の経緯

1月の楽天における**広告単価高騰→売上減少**を受け、2月に「Amazon価格引き上げ＋在庫のダム化」を開始。

| 時期 | 状況 |
|------|------|
| 1月 | 楽天の買取チラシ広告単価が高騰 → 楽天売上が前月比840万円減 |
| 1月 | Amazon構成比が63.1%に急増、手数料が過去最高の6,267万円 |
| 2月 | **Amazon価格を10%引き上げ、ダム戦略を開始** |
| 2月 | 一時的な利益減少を覚悟の上で構造転換に着手 |

---

## 🎯 ダム戦略とは

### 基本コンセプト

```
【従来】
出品 → Amazon即売れ（安売り） → 手数料15%支払い → 利益圧迫

【ダム戦略】
出品 → Amazon価格10%UP（フィルター化）
              ↓
     Amazonで即売れしない「いい本」が在庫に滞留
              ↓
     他モール（楽天・ヤフオク・自社等）で「相対的に安い」と認識される
              ↓
     手数料の低いチャネルで成約 → 利益率UP
```

### Amazonの役割の転換

| 従来 | ダム戦略後 |
|------|-----------|
| 全在庫の「吸い上げ装置」 | 高単価品の「フィルター」 |
| 安売りでも数を捌く場 | 高くても買う層の「ショーケース」 |
| 売上の63%を占める | **売上の45%以下に抑制** |

| 平均単価（ASP） | 805円 | **915円** | **900円台を維持** |

### 在庫の許容範囲

| 指標 | 現状 | 目標 |
|------|------|------|
| 在庫数 | 約10.4万冊 | **約12.5万冊（20%増）** |
| 在庫滞留日数 | - | **約6日分の出品待機列** |
| 目的 | - | 他モールでの「見つけられ待ち」の時間を確保 |

> **12.5万冊の在庫 ＝ 約6日間の滞留**
> この6日間があれば、楽天・メルカリ・ヤフオク等の巡回ユーザーにリーチでき、
> Amazonに頼らずとも販売率を90%へ回帰させるための十分なバッファとなる。

## 💡 重要な認識

### 在庫増は「投資」である

在庫が目標の12.5万冊に近づくまでの間、一時的にキャッシュフローが重くなるように見えるが、これは**「手数料をAmazonに払う代わりに、自社の資産（在庫）に変えている」投資期間**。

### 楽天広告費の正体

楽天で月額約1,400万円を投じている「楽天チラシ」は、販売促進費ではなく**「買取（仕入れ）のための広告費」**。良質なダム（在庫）を作るための原材料調達費という位置づけ。

### 自社倉庫発送の強み

FBAは使用せず、全て上田・埼玉の自社倉庫から発送。Amazon手数料の大部分は**販売手数料とカテゴリー成約料**であり、そこにさらに自社の荷造運賃が乗る構造。
