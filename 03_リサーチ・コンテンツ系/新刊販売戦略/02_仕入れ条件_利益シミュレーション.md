## 🎯 仕入れルート別の戦略

### 日販（78%）

- **用途**：品揃え拡充、ロングテール対応
- **リスク**：薄利のため、ポイント還元競争に巻き込まれると赤字
- **対策**：売れ筋のみを絞って仕入れ、死蔵在庫を作らない

### トランスビュー / 子どもの文化普及協会（70%）

- **用途**：メインの仕入れルート
- **対象ジャンル**：人文・社会科学・専門書など
- **メリット**：返品不可だが、楽天という出口があれば在庫リスクを許容できる

### 出版社直取引（60%）

- **用途**：高収益の主力商品
- **条件**：販売実績を積んでから交渉
- **目標**：年間販売額を背景に、大手出版社との直取引を拡大

## 🎤 出版社への60%直取引 営業ピッチ

### Step 2（2026年11月〜）での出版社営業で使う交渉材料

> **「掛率60%でバリューブックスに卸してくれませんか？」**

### バリューブックスが出版社に提示できる6つの条件

| # | 条件 | 詳細 |
|---|------|------|
| ① | **掛率60%** | 通常の書店は78%で仕入れ → 出版社の取り分は40%（通常22%） |
| ② | **まとめ仕入れ** | SKYPOD稼働（11月）で空いたスペースにまとまった量を仕入れ |
| ③ | **物流代行** | 出版社の指示で、さまざまな場所への発送も行う（3PL機能） |
| ④ | **著者還元** | 著者の発信で売れた場合、**書店取り分の30%を著者に返す** |
| ⑤ | **販売努力** | 自社ユーザー30万人、プロアカウント書店、積読チャンネル8万人にリーチ |
| ⑥ | **お試しOK** | まずは少量から始めて効果を検証できる |

### 著者還元モデルの計算例（定価1,500円の本）

```
【通常の書店の場合】
出版社 → 書店に78%（1,170円）で卸す
出版社の取り分 = 1,500円 - 1,170円 = 330円（22%）

【バリューブックス直取引の場合】
出版社 → バリューブックスに60%（900円）で卸す
出版社の取り分 = 1,500円 - 900円 = 600円（40%）★ ほぼ倍

バリューブックスの取り分 = 600円
  → うち30%を著者に還元 = 180円
  → バリューブックスの残り = 420円
  → 変動費（送料100円＋手数料等200円）を引いて = 純利益120〜220円
```

> **出版社にとってのメリット：取り分が22% → 40%にほぼ倍増**
> **著者にとってのメリット：通常の印税150円に加え、発信で売れた分に180円が追加**
> **バリューブックスにとってのメリット：1冊あたり120〜220円の利益**
