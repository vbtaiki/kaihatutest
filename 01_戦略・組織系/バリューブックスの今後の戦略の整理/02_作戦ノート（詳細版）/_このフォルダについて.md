## 📚 作戦ノートの特徴

### 💬 カジュアルな文体

```
❌ 「本システムは、画像認識技術を活用した...」
✅ 「本棚をスマホでピッ！すると自動で本を認識しちゃうんだ！」
```

読みやすく、楽しく、分かりやすい口調で書かれています。

### 🎯 「なぜやるか」を重視

- 単なる機能説明ではない
- **背景・思想・ビジョン**を丁寧に説明
- チーム全体で目的を共有

### 📖 具体例が豊富

- 実際のユーザー体験
- 具体的な数字
- 成功イメージ

### 🔄 ストーリー形式

```
ユーザーの課題
    ↓
バリューブックスの解決策
    ↓
実現後の世界
```

## 📊 プロジェクトシートとの違い

| 項目 | プロジェクトシート | 作戦ノート（このフォルダ） |
|------|-------------------|----------------------|
| **長さ** | 2ページ | 5〜10ページ |
| **文体** | ビジネス | カジュアル |
| **内容** | 概要・数字中心 | 背景・思想・具体例 |
| **対象** | 実務担当者 | 全員 |
| **目的** | タスク実行 | 理解・共感 |

**使い分け:**
- **タスク実行:** プロジェクトシート
- **背景理解:** 作戦ノート（このフォルダ）

