# プロジェクト①：協力型買取（本棚スキャン）

**担当者全員が5分で理解できるシート**

---

## 📋 プロジェクト概要

### 何を作る？（一言で）
**スマホで本棚を撮るだけで、AI が高く買取価格を提示してくれるアプリ**

### なぜ作る？
- **課題**: 従来の買取は「楽だけど安い」、フリマは「高いけど面倒」
- **解決策**: AIと協力で「簡単なのに高い」を実現
- **効果**: 買取価格が従来の **2〜3倍** になり、ユーザー満足度UP

## 🔄 ユーザーの流れ（簡単に）

```
【ステップ1】本棚をスマホで撮影（30秒）
  ↓ AIが自動認識
【ステップ2】価格が即座に表示される
  ↓ 状態を簡単入力（協力）
【ステップ3】価格UP！即確定
  ↓ 本を箱詰めして発送
【ステップ4】即入金
  ↓ 後日...
【ボーナス】予測より高く売れたらポイント還元！
```

## 💻 システム構成（ざっくり）

```
┌───────────────────────────┐
│  スマホアプリ (Flutter)   │
│  ・カメラで撮影           │
│  ・価格表示・申込         │
└──────────┬────────────────┘
           │ 画像送信
┌──────────▼────────────────┐
│  画像認識AI (Python)      │
│  ・背表紙を切り出し       │
│  ・OCRで文字認識          │
└──────────┬────────────────┘
           │ 書籍ID
┌──────────▼────────────────┐
│  予測エンジン (Python)    │
│  ・販売価格を予測         │
│  ・買取価格を算出         │
└──────────┬────────────────┘
           │
┌──────────▼────────────────┐
│  データベース             │
│  PostgreSQL + Redis       │
└───────────────────────────┘
```

### 使う技術

| 部分 | 技術 | 理由 |
|------|------|------|
| スマホアプリ | Flutter | iOS/Android同時開発 |
| 画像認識 | Google Cloud Vision | 精度95%、日本語対応 |
| 予測モデル | LightGBM | 表データに強い |
| サーバー | Python FastAPI | AI連携が簡単 |
| データベース | PostgreSQL | 安定、実績多い |

## ⚠️ リスクと対策

### リスク1: 画像認識精度が不足
**対策**: 
- 初期は1冊ずつスキャン（難易度下げる）
- Unknown判定を積極的に使う（無理に判定しない）
- ユーザーが手動入力できる仕組み

### リスク2: 予測が外れる
**対策**: 
- 完璧な予測は不要（説明可能な予測でOK）
- 外れた場合もボーナスで還元するから問題なし
- 段階的にモデル改善

### リスク3: ユーザーが虚偽申告
**対策**: 
- 信頼度スコアで管理
- 悪質なユーザーは制限
- 初期は抜き取り検査
