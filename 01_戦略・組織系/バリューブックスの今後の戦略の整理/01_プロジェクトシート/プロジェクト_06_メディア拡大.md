# プロジェクト⑥：メディア拡大（動画・コンテンツ）

**担当者全員が5分で理解できるシート**

---

## 📋 プロジェクト概要

### 何を作る？（一言で）
**積読チャンネルを軸に、複数の動画メディアを展開して面で攻める**

### なぜ作る？
- **課題**: 1チャンネルだけでは限界、もっと色んな人に届けたい
- **解決策**: 新チャンネル＋編集ギルド＋のれん分けで多角化
- **効果**: 認知拡大、売上・買取に直結

## 👥 誰が使う？（ターゲット）

- **メインユーザー**: 本好き全般（20〜50代）
- **利用シーン**: 通勤中、休憩時間、就寝前
- **効果**: 認知→購入・買取に繋がる

---

## 🔄 コンテンツの流れ（簡単に）

```
【企画・撮影（社内）】
  ↓ 素材を共有
【編集（外注ギルド）】
  ↓ 編集済み動画
【公開（YouTube等）】
  ↓ 視聴者が見る
【概要欄から購入・買取】
```

---

## 💻 システム構成（ざっくり）

```
┌──────────────────────┐
│  企画・撮影チーム     │
│  (社内2名)           │
└─────────┬────────────┘
          │ 素材共有
┌─────────▼────────────┐
│  編集ギルド          │
│  (外注10名プール)    │
└─────────┬────────────┘
          │ 完成動画
┌─────────▼────────────┐
│  YouTube等で公開     │
│  ・積読チャンネル    │
│  ・Video Podcast     │
│  ・著者密着          │
└─────────┬────────────┘
          │
┌─────────▼────────────┐
│  概要欄リンク        │
│  → 販売・買取サイト  │
└──────────────────────┘
```

### 使う技術

| 部分 | 技術 | 理由 |
|------|------|------|
| 編集管理 | Notion | タスク・進捗管理 |
| コミュニケーション | Slack | ギルドとの連絡 |
| 素材共有 | Google Drive / Frame.io | 大容量対応 |
| 決済 | PayPal | 編集者への支払い |

## ⚠️ リスクと対策

### リスク1: 編集品質のバラつき
**対策**: 
- A級編集者によるレビュー
- 編集ガイドライン作成
- フィードバックの型化

### リスク2: ギルドメンバーの離脱
**対策**: 
- 常時15名プール（稼働10名）
- 継続的な新規採用
- 報酬・評価制度の整備

### リスク3: YouTuberとのトラブル
**対策**: 
- 契約書の整備（弁護士監修）
- 定期的なコミュニケーション
- 収益の透明性を保つ
