# プロジェクト③：本のある暮らしグッズ（物販）

**担当者全員が5分で理解できるシート**

---

## 📋 プロジェクト概要

### 何を作る？（一言で）
**丸山珈琲やMinimalと組んで、本好きが喜ぶグッズを販売するECサイト**

### なぜ作る？
- **課題**: 書籍だけでは売上に限界、お客さんの単価が上がらない
- **解決策**: 本＋グッズで「本のある暮らし」全体を提案
- **効果**: 客単価 **+¥1,500**、売上の多角化

## 💻 システム構成（ざっくり）

```
┌─────────────────────────────┐
│  バリューブックス本体サイト │
│  (会員ID管理)               │
└──────────┬──────────────────┘
           │ SSO連携
┌──────────▼──────────────────┐
│  Shopify (グッズ専用)       │
│  ・商品登録                 │
│  ・カート・決済             │
│  ・在庫管理                 │
└──────────┬──────────────────┘
           │
┌──────────▼──────────────────┐
│  倉庫（SKYPOD or 別拠点）   │
│  ・在庫保管・発送           │
└─────────────────────────────┘
```

### 使う技術

| 部分 | 技術 | 理由 |
|------|------|------|
| ECサイト | Shopify | カート開発不要、即販売可能 |
| SSO連携 | Shopify Multipass | ログイン統合 |
| 在庫管理 | Shopify標準機能 | 自動化 |
| 決済 | Shopify Payments | 多様な決済方法 |

## ⚠️ リスクと対策

### リスク1: 在庫が売れ残る
**対策**: 
- 小ロット仕入れ徹底（各商品10〜30個）
- 売れ筋データを毎週チェック
- 滞留在庫は早めにセール

### リスク2: バイヤーが辞める
**対策**: 
- 複数バイヤー体制（2名目を早めに採用）
- 仕入れ先情報をドキュメント化
- 社内にMD知見を蓄積

### リスク3: Shopifyと既存システムの連携不具合
**対策**: 
- 初期は完全分離運用
- ポイント連携は段階的に
- エラーログの詳細監視
