## 🔗 Markdownとの違い

| 項目 | Markdown | HTML |
|------|----------|------|
| 編集 | ⭐ 簡単 | 難しい |
| 閲覧 | 要ツール | ⭐ ブラウザで即開ける |
| デザイン | シンプル | ⭐ 美しい |
| 共有 | プレーンテキスト | ⭐ 視覚的 |
| 検索 | ⭐ grep等で高速 | 難しい |
| 管理 | ⭐ Git向き | Git管理は可 |

**使い分け:**
- **編集・管理:** Markdown（`01_プロジェクトシート/`等）
- **閲覧・共有:** HTML（このフォルダ）

---

## ⚠️ 注意事項

### ファイルの同期

- Markdownを編集してもHTMLは**自動更新されません**
- HTMLを更新する場合は再生成が必要

### リンク

- このフォルダ内のHTMLファイル間はリンク済み
- 外部ファイルへのリンクは一部相対パス

### ブラウザ

- Chrome、Firefox、Safari、Edge すべて対応
- JavaScript不要（静的HTML）

## 🆘 トラブルシューティング

### Q1. ダブルクリックで開かない

**A:** 右クリック → 「プログラムから開く」→ ブラウザを選択

### Q2. デザインが崩れている

**A:** 最新のブラウザを使用してください（IE非対応）

### Q3. リンクが動かない

**A:** ファイル名を変更していないか確認
