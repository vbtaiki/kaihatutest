## 🔍 タグの使い方

### 検索例

#### 最優先プロジェクトを表示
```
tag:#最優先
```

#### Python関連のプロジェクトを表示
```
tag:#Python
```

#### ユーザー向けプロジェクトを表示
```
tag:#ユーザー向け
```

#### Phase1のプロジェクトを表示
```
tag:#Phase1-仕込み
```

### 複合検索

#### 技術開発 × 最優先
```
tag:#技術開発 tag:#最優先
```

#### AI関連 × リスク高
```
tag:#AI tag:#リスク高
```

## 🎨 タグの色分け（推奨）

Obsidianのカスタムスタイル、またはTheme設定で色分け推奨：

- 🔴 #最優先 → 赤
- 🟡 #重要 → 黄色
- 🟢 #通常 → 緑
- #技術開発 → 青
- #事業開発 → 紫
- #マーケティング → オレンジ

## 📝 タグ付けルール

### 必須タグ（3つ）

すべてのプロジェクトファイルには以下を必ず付ける：

1. **タイプ:** #技術開発 / #事業開発 / #マーケティング
2. **優先度:** #最優先 / #重要 / #通常
3. **領域:** #買取 / #販売 / #物流 / #ポイント / #メディア

### 推奨タグ（2-5個）

必要に応じて以下を追加：

- 主要技術スタック（2-3個）
- ステークホルダー（1個）
- リスクレベル（1個）

### 最大推奨数

**1ファイルあたり8個まで**（多すぎると管理困難）
