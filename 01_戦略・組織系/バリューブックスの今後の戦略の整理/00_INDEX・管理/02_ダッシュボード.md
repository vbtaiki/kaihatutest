## 📊 Dataview クエリ（プラグイン有効時）

### すべてのプロジェクト

```dataview
TABLE 
  status as "状態",
  priority as "優先度",
  budget as "予算"
FROM "プロジェクト"
WHERE type = "project"
SORT priority DESC
```

### 今週のタスク

```dataview
TASK
WHERE contains(file.name, "プロジェクト")
  AND !completed
  AND due <= date(today) + dur(7 days)
SORT due ASC
```

TABLE
