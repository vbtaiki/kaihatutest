## 🔧 推奨プラグイン

### 必須

#### 1. **Dataview**
- 用途：ダッシュボードの自動集計
- 設定：有効化するだけ

### 推奨

#### 3. **Calendar**
- 用途：日付ベースのノート管理
- 設定：週の開始を月曜日に

#### 4. **Kanban**
- 用途：タスクのカンバン管理
- 設定：[[02_ダッシュボード]] のタスクをカンバン化

#### 5. **Tag Wrangler**
- 用途：タグの一括変更
- 設定：[[03_タグ・分類体系]] と連携

#### 6. **Graph Analysis**
- 用途：グラフビューの分析強化
- 設定：プロジェクト間の関連性を可視化

## 🔗 リンク活用法

### 双方向リンク

Obsidianの最大の特徴。すべてのプロジェクトファイルには相互リンクが設定済み。

**例：**
- [[プロジェクト_01_協力型買取]] ⇄ [[プロジェクト_04_SKYPOD倉庫]]
- データ連携で相互依存

**確認方法：**
1. ファイルを開く
2. 右サイドバー「Backlinks」を確認
3. どのファイルからリンクされているか表示

### エンベッド（埋め込み）

他のノートの内容を埋め込み可能：

```markdown
![[プロジェクト_01_協力型買取#KPI]]
```

→ 協力型買取のKPI部分だけを埋め込み

## 📊 Dataview活用例

### 全プロジェクト一覧

```dataview
TABLE 
  priority as "優先度",
  status as "ステータス",
  budget as "予算"
FROM "プロジェクト"
WHERE type = "project"
SORT priority DESC
```

### 今週のタスク

```dataview
TASK
WHERE !completed
  AND due <= date(today) + dur(7 days)
SORT due ASC
```

### KPI達成率

```dataview
TABLE 
  kpi-target as "目標",
  kpi-current as "現状",
  round((kpi-current / kpi-target) * 100) + "%" as "達成率"
FROM "プロジェクト"
WHERE kpi-target != null
```

## 🚨 トラブルシューティング

### Q1. リンクが機能しない

**A:** ファイル名が正確か確認。Obsidianは大文字小文字を区別します。

### Q2. Mermaid図が表示されない

**A:** コアプラグイン「Mermaid」が有効か確認。

### Q3. Dataviewが動かない

**A:** 
1. Community Plugin「Dataview」をインストール
2. 設定 > Dataview > Enable JavaScript Queries

### Q4. グラフが見づらい

**A:** 
1. グラフビュー設定を開く
2. 「Filters」でファイル数を絞り込み
3. 「Groups」で色分け
