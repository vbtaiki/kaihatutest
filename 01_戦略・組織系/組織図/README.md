# Value Books OS (VB-OS) 2026

## 概要

バリューブックスの「現在」と「未来」を同期するためのオペレーティングシステム。
中村大樹の脳内にある「期待値」と、各チームの「実行状況」を接続します。

> **Organization as Code** — 組織図、戦略、タスクをコードのように管理する

---

## 🎯 2026年のゴール

**売上100億円 & 本を愛する人々との協働事業体への進化**

### 3つの柱

1. **循環型ポイント経済圏** — 売る・買うのシームレス化
2. **倉庫革命とスマート買取** — SKYPOD × 本棚スキャン、検品工数1/4
3. **プロアカウントとMD深化** — パートナー共創と物販

## 💡 設計思想

| 原則 | 説明 |
|------|------|
| **Organization as Code** | 組織図、戦略、タスクをコードのように管理する |
| **Flat Network** | 上下関係ではなく「機能」でチームを分ける。経営陣も「0-governance」という機能 |
| **Founder's Sync** | 全プロジェクトに `Founder's Expectation` を設け、中村大樹の意図を同期 |
| **Variable Resolution** | ダッシュボードで自チームは「高解像度」、他チームは「低解像度」で表示 |

## 🔄 運用ルール

### 更新方法

Cursorに会話で伝えてファイルを更新させる：

```
「プロアカウントチーム、MDの方針を変えたい。『売る』より『ブランディング』重視に」
→ AIがteams/5-pro-account/README.mdのFounder's Expectation欄を更新
```

### 同期サイクル

1. **週次**: 各リーダーは `Founder's Expectation` を確認
2. **随時**: 状況が変わったらCursorに伝えて即時更新
3. **月次**: ダッシュボードで全体の進捗を確認

## 🌐 ダッシュボード

ブラウザで組織の状況を可視化：

```bash
# ローカルサーバー起動
cd dashboard && python3 -m http.server 8888

# ブラウザでアクセス
open http://localhost:8888
```

### 機能

- **解像度切り替え**: 自分のチームを選択すると詳細表示、他チームは概要表示
- **Founder's Expectation表示**: 選択したチームの期待値が見える
- **プロジェクト一覧**: 各チームの進行中タスク
