# バリューブックスの競合優位性

## 1. ポジショニング

### 「まとめて買うナンバーワン」

Amazon・楽天はプラットフォーマー（複数出品者の寄せ集め）。
バリューブックスは **「一社で全部」**。

| 比較項目 | Amazon | バリューブックス |
|---------|--------|----------------|
| 新刊在庫 | 自社+マケプレ | 自社（目標20万冊） |
| 中古在庫 | マケプレ各社 | 自社 |
| 送料（新刊5冊+中古5冊） | 1,500円〜 | 250円 |
| ポイント | 分断 | 統一 |

**1冊ずつ買う人** → Amazonで十分
**まとめて売る・買う人** → バリューブックスが圧倒的に得

---

## 2. ターゲット顧客

### 月に10冊以上読む人

- 年間購入コストが大きい → ポイントの価値が高い
- 読み終わった本を売りたい → 買取との連携が活きる
- まとめ買いする → 送料メリットが大きい

**ライトユーザーではなく「本を愛する人」のインフラになる**

---

## 3. 新刊戦略

### 「バリューブックス＝新刊も古本もどんな本でも手に入る」

#### Phase 1: 取次経由（原価率80%）
- 常時20万冊の新刊在庫を目指す
- 積読チャンネルで紹介した新刊は既に売れ始めている

#### Phase 2: 直接仕入れ（原価率60%）
- プロアカウントの営業を強化
- 出版社と直接取引

#### 出版社へのメリット
- バリューブックスと組むことで、**他の書店への物流機能**も手に入る
- VBが「出版社の物流パートナー」になる

---

## 4. 販売チャネル戦略

| チャネル | 現状 | 課題・方針 |
|---------|------|-----------|
| Amazon | ✅ 最大限活用 | 維持 |
| 楽天 | ✅ 最大限活用 | 維持 |
| メルカリ | △ 活用不十分 | 全本撮影（ベルトコンベア）で全商品出品へ |
| 自社サイト | 伸びしろあり | **ポイント経済圏**で差別化 |

### メルカリの課題と解決策
- **課題**: 表紙画像がない本を出品できていない
- **解決**: ベルトコンベアで全本撮影 → 全商品をメルカリでも販売可能に

---

## 5. 20万冊新刊へのロードマップ

### ハードル
1. **Phase 1**: 取次から仕入れるための資金
2. **Phase 2**: 利益率改善のための出版社直接取引交渉

### 流れ
資金確保 → 在庫構築 → 実績作り → 交渉力強化 → 直接取引

---

## 6. まとめ：バリューブックスで買う理由

1. **まとめ買いの送料が安い**（中古も新刊も一緒に）
2. **売ったポイントで買える**（買取→ポイント→購入のループ）
3. **新刊も古本も一緒に買える**（20万冊新刊+既存中古）
4. **著者とのコラボ特典がある**（発射台モデル）

**単独では勝てなくても、合わせ技で唯一無二のポジション**
