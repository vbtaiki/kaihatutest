# Team: ガバナンス & 文化

## 💭 Founder's Expectation (中村大樹の期待値)

> **「舗装道路」を作るだけの裏方ではない。**
> 
> バリューブックスにおいて、People（人）が健全に、そして誇りを持って働ける「土壌（環境）」を整えること。
> プロフィット（収益）は分散した各チームが責任を持って追う。このチームの責任は、そのプロセスにおいて「構造的に誰かを差別・排除していないか」を問い続け、ピープル・ガバナンスを確立すること。
> 
> ジェンダーギャップ解消やB Corpは、単なるラベルではなく、人が健やかに働くための「OS」として機能させてほしい。
