## 🎯 このプロジェクトのゴール

写真を撮るだけで本が売れ、倍額のポイントが貯まり、そのポイントで「ここでしか手に入らない読書グッズ」や「次の本」を買う。

### 成功基準

- [ ] ポイント受取率 **20%** 達成
- [ ] ポイント利用でのEC購入率 TBD%
- [ ] ポイント経由のリピート率向上
