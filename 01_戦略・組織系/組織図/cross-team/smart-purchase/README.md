## 🎯 このプロジェクトのゴール

ユーザーが「スキャン登録＋状態申告」することで、倉庫での検品をスキップし、その分をポイント倍額として還元する仕組みの確立。

```
┌─────────────────────────────────────────────────────────────┐
│                    スマート買取フロー                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  👤 ユーザー                                                │
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐     │
│  │ 本棚スキャン │ → │  状態申告   │ → │   発送     │     │
│  │  (撮影)     │    │(良い/普通/悪い)│    │            │     │
│  └─────────────┘    └─────────────┘    └─────────────┘     │
│                                              ↓              │
│  🏭 倉庫                                                    │

│  │  ダイレクト入庫レーン（検品スキップ）            │       │
│  │  → 直接保管 → サンプリング検査                   │       │

│  💰 還元                                                    │
│  ┌─────────────┐                                           │
```
