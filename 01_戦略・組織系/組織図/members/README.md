## 役割の種類

| 役割タイプ | 説明 |
|---|---|
| **Leader** | チーム/プロジェクトのリーダーとして責任を持つ |
| **Member** | チーム/プロジェクトのメンバーとして参加 |
| **Client** | 依頼者として関与（運営には関わらない） |
| **Advisor** | アドバイザーとして助言・監督 |
| **Stakeholder** | 利害関係者として情報共有を受ける |

## 新メンバー追加方法

1. `_templates/member.md` をコピー
2. `members/` フォルダに `名前.md` として保存
3. 情報を記入
4. この `README.md` の該当箇所に追加
