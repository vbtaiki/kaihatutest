# 📘 運用ガイド：AIとの協働で組織図を育てる

> このシステムは、自然言語でAIに指示を出すだけで組織情報が整理・更新されていく仕組みです。

---

## 基本的な考え方

```
あなたの頭の中の情報・アイデア
         ↓
   AIへの自然言語での指示
         ↓
   適切なファイルが自動更新
         ↓
   組織の実行力が上がる
```

**ポイント**: 構造やフォーマットを気にする必要はありません。AIが適切なファイルを特定し、適切な形式で記録します。

---

## 🗣️ 指示の出し方（例文集）

### 1. 人物に対する指示

**新しい役割・担当を追加する**
```
「清水さんに、新しく入ってくるパートスタッフの採用面接も担当してほしい」
「内沼さんを新規メディアプロジェクトのリーダーにする」
```

**スキルや専門性を記録**
```
「ヨシダはReactとTypeScriptが得意。インフラも少しわかる」
「飯田は動画編集とサムネイルデザインのスキルがある」
```

**現在のフォーカスを更新**
```
「今週、小平さんはLINE登録キャンペーンの設計に集中してもらう」
```

---

### 2. チーム・プロジェクトに対する指示

**新しいプロジェクトを追加**
```
「倉庫チームに『繁忙期対応マニュアル作成』プロジェクトを追加して」
「買取部門で『法人買取サービス』を新しく立ち上げたい」
```

**プロジェクトの詳細を追加**
```
「SKYPOD導入の第1フェーズは2月末まで。業者はExotec社で決定」
「ポイント経済圏のリスクに『競合サービスの動向』を追加」
```

**マイルストーン・期限を設定**
```
「本棚スキャン改善のPhase1は3月中にリリース目標」
「積読チャンネルのグッズ第一弾は4月発売予定」
```

---

### 3. 組織全体・横断的な指示

**チーム間連携を記録**
```
「ポイント経済圏は買取とWeb開発だけでなく、経理とも連携が必要」
「スマート買取はカスタマーサポートチームとも調整が必要になりそう」
```

**KPIや目標の更新**
```
「買取部門のポイント受取率、現状は8%だった」
「倉庫の検品工数、まず50%を中間目標にする」
```

**新しいチーム・部門を作る**
```
「経理総務チームを新しく追加して。メンバーは後で決める」
「カスタマーサポートチームを作りたい」
```

---

### 4. 情報の確認・整理

**現状確認**
```
「清水さんが今担当しているプロジェクトを教えて」
「買取部門のKPIの進捗状況を見せて」
「ジェンダーギャップ解消プロジェクトに関わっている人は誰？」
```

**全体俯瞰**
```
「今月期限のプロジェクトを全部教えて」
「ブロッカーが発生しているプロジェクトはある？」
「各チームの今週のフォーカスをまとめて」
```

## 🔄 更新のタイミング

### 日常的に
- アイデアが浮かんだとき
- 会議で決まったことがあるとき
- 誰かと話して方針が変わったとき

### 週次（推奨）
- 「各チームの今週のフォーカスを更新して」
- 「先週の進捗を記録して」

### 月次
- 「今月の振り返りをまとめて」
- 「KPIの現状を更新して」

## 💡 Tips

### 1. 曖昧でもOK
```
❌ 完璧に整理された指示を出さなければ...
✅ 「なんかこういうことやりたいんだけど」でOK
```
AIが質問してくれるので、対話しながら明確にしていけます。

### 2. 複数のことを一度に
```
「清水さんをSKYPODのリーダーにして、
 林さんとセトさんも参加メンバーに追加。
 あと開始日は2月1日で」
```
一度の指示で複数ファイルが更新されます。

### 3. 「〇〇したい」でOK
```
「買取のリピート率を上げたい」
→ AIが適切なプロジェクトやタスクを提案してくれます
```

### 4. メモ的に使う
```
「清水さんとの1on1で話したこと：
 - SKYPODは想定より導入に時間がかかりそう
 - 人員配置は林さんに任せる方向
 これを記録しておいて」
```

## 🪄 AI（Cursor）を使いこなす応用テクニック

### 1. 「期待値」から逆算して行動を提案させる
```
「倉庫チームの期待値を踏まえて、今月リーダーがやるべき具体的なアクションを5つ提案して」
「B Corpの考え方を、Webサイトの文言に落とし込みたい。ドラフトを3つ作って」
```

### 2. プロジェクトの壁打ち相手にする
```
「SKYPOD導入のリスクとして、他に考えられることは何？ 過去の事例から推測して」
「このプロジェクト、誰をアサインするのが最適だと思う？ メンバーのスキル表から考えて」
```

### 3. 情報の整合性をチェックする
```
「戦略ロードマップと、現在の各チームのKPIに矛盾がないかチェックして」
「最近の更新履歴を要約して、今週の全社ミーティング用のトピックを作って」
```
