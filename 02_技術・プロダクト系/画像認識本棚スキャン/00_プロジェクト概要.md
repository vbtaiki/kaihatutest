# 本棚スキャン OCR検索プロジェクト

## 📋 プロジェクト概要

**目的**: 本棚の写真から背表紙を自動認識し、書籍を特定するシステムの開発

**状態**: ✅ **本棚スキャン最新版 完成**（2026/02）

**期間**: 2025年11月〜継続中

**参加者**:
- バリューブックス: 中村様、片山様、佐々木様、相良様、吉田様、竹本様
- 開発: 落合、キンスウェイ

---

## 🎯 プロジェクトのゴール

1. **背表紙画像から書籍を自動特定**
   - 本棚の写真を撮影
   - SAM3で背表紙を個別に切り出し
   - OCRでテキスト読み取り
   - OpenSearchで書誌データベースを検索
   - AIで最終判定

2. **高精度な判定**
   - 採用率: 70%以上
   - 正解率: 98%以上（不正解を最小化）

3. **背表紙画像データベースの構築**
   - 特定済みの背表紙画像を蓄積
   - 将来の照合に活用

---

## 🏆 最新版の完成（2026/02）

多くの本について **背表紙画像** と **その画像をOCRした結果** の両方を蓄積し、これらを組み合わせて判定する仕組みが完成。

```
┌─────────────────────────────────────────────────────┐
│              本棚スキャン 最新版の仕組み                 │
├─────────────────────────────────────────────────────┤
│                                                       │
│  📷 本棚写真 → SAM3で切り出し → 個々の背表紙画像       │
│                                                       │
│  各書籍が持つデータ:                                    │
│  ┌──────────────┐   ┌──────────────┐                  │
│  │ 🖼️ 背表紙画像 │ + │ 📝 OCR結果   │ → 組み合わせ判定 │
│  │  （実際の画像） │   │（テキスト情報）│                  │
│  └──────────────┘   └──────────────┘                  │
│                          ↓                             │
│              🔍 OpenSearch検索 + 🤖 AI判定              │
│                          ↓                             │
│                    📚 書籍の特定                        │
│                                                       │
│  ✅ 本棚指定あり: 正解率 98.5%（2,031件検証）           │
│  🔄 本棚指定なし: 正解率 95.3%（改善検討中）            │
│                                                       │
└─────────────────────────────────────────────────────┘
```

**ポイント**: 背表紙画像とOCR結果の蓄積が進むほど、照合精度が上がり、本棚を指定しない広範囲の検索にも対応できるようになる。

## 🔧 技術スタック

| カテゴリ | 技術 | 用途 |
|---------|------|------|
| 画像セグメンテーション | **SAM3** (Meta) | 本棚画像から背表紙を切り出し |
| OCR | **LINE OCR** / **Gemini** | 背表紙からテキスト読み取り |
| 検索 | **OpenSearch** | 書誌データベース検索 |
| AI判定 | **OpenAI GPT-5 mini** | スコア差が微妙な本の判定 |
| AI判定 | **Gemini 3 Flash** | 背表紙画像＋候補での最終判定 |

## 📊 現在の精度

### 全体フロー

```
本棚画像
    ↓
SAM3で背表紙切り出し
    ↓
LINE OCRでテキスト読み取り
    ↓
OpenSearchで候補検索
    ↓
①ルールベースチェック
    ↓ 不採用の場合
②OpenAI AI判定（候補10件から選択）
    ↓ 判定できない場合
③Gemini AI判定（背表紙画像＋候補）
    ↓
最終結果
```

### 精度実績：本棚指定あり検索（2026/01/30時点、UB74本棚 2,031件）

| フェーズ | 採用数 | 不正解数 | 採用率 | 正解率 |
|---------|--------|----------|--------|--------|
| ①ルールベース | 1,529件 | 4件 | 75.3% | 99.7% |
| ②OpenAI追加判定 | +298件 | +21件 | - | 93.0% |
| ③Gemini追加判定 | +200件 | +5件 | - | 97.5% |
| **合計** | **2,027件** | **30件** | **99.8%** | **98.5%** |

### 精度実績：本棚指定なし検索（2026/02/13時点、UB74本棚 2,031件）

全体のDBから検索した場合の精度検証。Gemini AI（Gemini 3 Flash Preview）で全2,031件を一括判定。

| 判定結果 | 本棚指定あり | 本棚指定なし | 変化 |
|---------|------------|------------|------|
| 採用・正解 | 1,854件（91.29%） | 1,694件（83.41%） | ▼ 約8pt低下 |
| 採用・不正解 | 5件（0.25%） | 83件（4.09%） | ▲ 大幅増加 |
| 不採用 | 172件（8.47%） | 254件（12.51%） | ▲ 増加 |

**課題**: 不正解が5件→83件に増加。似た本の誤判定が主な原因。改善策を検討中。
