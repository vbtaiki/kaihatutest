## 1. 画像セグメンテーション（SAM3）

### 概要
Meta社のSegment Anything Model 3を使用し、本棚画像から個々の背表紙を切り出す。

### 導入経緯
- **SAM2以前**: 2冊分の背表紙が1つの画像になるケースが多発
- **SAM3導入後**: 切り出し精度が大幅向上、付箋の除外も改善

### 設定パラメータ

| パラメータ | 値 | 説明 |
|-----------|-----|------|
| 閾値 | 0.8 | 認識の信頼度閾値（0.5→0.8に変更） |
| モデル | 静止画用 | 動画用モデルは重いため不使用 |

### 既知の課題

1. **2冊が1冊と認識される**
   - 原因: 付箋があること
   - 発生率: 単行本棚80枚中3枚程度
   - 対策: 閾値を0.8に上げることで軽減

2. **同一書籍が複数回認識される**
   - 原因: 端にある書籍、付箋で分断されているケース
   - 対策: 重複検出ロジックで対応

3. **雑誌棚の精度が低い**
   - 原因: 細い背表紙が多い
   - 対策: 雑誌は別処理を検討

### 参考リンク
- Ultralytics SAM3: https://docs.ultralytics.com/ja/models/sam-3/
- Hugging Face: https://huggingface.co/facebook/sam3

## 2. OCR処理

### 使用サービス

| サービス | コスト | 精度 | 用途 |
|---------|--------|------|------|
| LINE OCR | 0.3円/画像 | 普通 | 通常処理 |
| Gemini 3 Flash | 6-9円/画像 | 高い | 高精度が必要な場合 |

### Gemini OCRの利点

1. **構造化出力が可能**
   - タイトル、著者、出版社、巻数を個別に抽出
   - 帯で隠れている巻数を検出（obi_hide_volume: true/false）

2. **コミック背表紙に有効**
   - 飾り文字の読み取り精度が高い
   - 巻数の認識精度が良好

### プロンプト例（Gemini）

```json
{
  "title": "ワンピース",
  "volume": "35",
  "author": "尾田栄一郎",
  "publisher": "集英社",
  "obi_hide_volume": false
}
```

## 3. OpenSearch検索

### 検索フロー

```
OCR結果（テキスト）
    ↓
OpenSearchクエリ生成
    ↓
書誌データベース検索
    ↓
上位N件の候補を取得（スコア付き）
```

### 検索モード

| モード | 説明 | 用途 |
|--------|------|------|
| 本棚指定あり | 在庫データ内のみ検索 | 高精度判定 |
| 本棚指定なし | 全データから検索 | 広範囲検索 |

### 検索条件の工夫

1. **出版社絞り込み**
   - OCRで出版社が特定できた場合、その出版社に絞り込み
   - 2つ以上の出版社名が含まれる場合は除外

2. **在庫データ内検索**
   - 対象の本のASIN/ISBN10を指定して検索
   - 先頭100件ではなく、明示的に指定した検索が可能

### 検索の課題

1. **洋書のスコアが低くなる**
   - 原因: アルファベットのみの単語はngramではなく単語検索になるため
   - 対策: 洋書の場合は足切りラインを50点に緩和

2. **巻数検索の問題**
   - 「ワンパンマン 35」で検索するとヒットしない場合あり
   - 巻数表記が「09」のように0埋めが必要な場合あり

## 4. 判定ロジック

### ①ルールベースチェック

```
採用条件:
  - 候補2のスコア ≤ 候補1のスコア × 0.6
  - スコアの絶対値が閾値以上
    - 洋書: 50点以上
    - その他: 100点以上
  - 2つ以上の出版社名が含まれていない
  - 出版社が特定できた場合はその出版社に絞り込み

除外条件:
  - 候補1と候補2が隣り合う本で、タイトルが似ていない場合
    （共通文字が3文字以下）
  - 本棚指定なし検索で候補1が在庫データにない場合
```

### ②OpenAI AI判定

```
入力:
  - OCRテキスト
  - 候補1〜10のJSON（タイトル、著者、出版社等）

出力:
  - 正解のid
  - 判断できない場合: None

使用モデル: GPT-5 mini（5mini以上は結果変わらず）
コスト: 1冊あたり0.1円以下
```

### ③Gemini AI判定

```
入力:
  - 背表紙画像
  - 候補のJSON情報

出力:
  - 正解のid
  - 判断できない場合: None

使用モデル: Gemini 3 Flash Preview
コスト: 1冊あたり0.2円程度
```

## 5. 似ている本の対応

### 問題となるケース

1. **巻数違い**
   - 同じタイトルで巻数だけ異なる
   - 例: ワンピース 1巻〜100巻

2. **年・月違いの定期刊行物**
   - 例: 地球の歩き方 '95〜'96年版 vs '96〜'97年版

3. **シリーズ物**
   - タイトルに異なるキーワードが含まれるがシリーズは同じ
   - 例: 地球の歩き方 イタリア vs 地球の歩き方 フランス

4. **複数出版社の類似本**
   - 資格試験の対策本など
   - 例: 刑事訴訟法（著者・出版社が全く同じで版違い）

### 対応方針

- 似ている本がある場合は**不採用**にする
- 次のフェーズで「似ている本グループ」を作成して対応
- コミックセットの対応はSAM3対応後に実施

## 6. 通常版と完全版の判別

### 判別可能な例

| 作品 | 通常版の特徴 | 完全版の特徴 |
|------|-------------|-------------|
| スラムダンク | - | 「by INOUE TAKEHIKO」あり |
| ツバサ | 上部にKCMコード＋KC MAGAZINE | 上部にKODANSHA MAGAZINE COMICS |
| 霊感商法株式会社 | 出版社が異なる | レーベルが「集英社文庫」等 |

### 対応方針
- データベースにOCR結果を保存して判別に活用
- 正解画像があれば容易に判別可能
