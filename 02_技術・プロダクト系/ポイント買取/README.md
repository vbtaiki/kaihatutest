**🔄 構成：オリジナル案とCURSOR案は完全に独立しており、それぞれ内部だけで循環する設計**

## 🔄 循環システムの仕組み

### 共通ナビゲーション

すべてのページに以下の要素を配置し、自然な循環を実現：

1. **ヘッダーナビゲーション**
   - マイページ
   - 購入履歴
   - お気に入り
   - ランクシステム
   - ポイント残高表示

2. **コンテキスト別リンク**
   - 買取完了 → 予約カート・おすすめ本
   - おすすめ本 → お気に入り・即購入
   - お気に入り → まとめて購入・おすすめ本
   - 購入完了 → ランク確認・リピート買取
   - ランクページ → 買取申込・マイページ

3. **マイページをハブに**
   - すべての機能へ1クリックでアクセス
   - 統計情報で次のアクションを提案
   - クイックアクションボタン

### 循環のメリット

- **離脱率の低減**: 常に次のアクションが明確
- **エンゲージメント向上**: 複数ページを自然に回遊
- **購入率アップ**: おすすめ→お気に入り→購入の流れ
- **リピート促進**: 購入後も買取・ランクへ誘導
- **LTV最大化**: 循環することでユーザーの生涯価値が向上
