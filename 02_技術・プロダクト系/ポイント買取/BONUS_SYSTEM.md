# ボーナスシステム説明

## 📊 ボーナス体系

バリューブックスの買取には、**2つの独立したボーナス**があります：

### 1. ソクフリボーナス（+10%）
**査定結果の連絡を待たずに買取了承**する場合に適用されます。

- **ソクフリする**: 査定額+10%
- **ソクフリしない**: ボーナスなし（通常買取）

### 2. ポイント受け取りボーナス（+20%）
**買取金額をポイントで受け取る**場合に適用されます。

- **ポイント受け取り**: 査定額+20%
- **現金振込**: ボーナスなし

---

## 💰 ボーナス組み合わせ例

基本買取額が **16,273円** の場合：

| 選択 | ソクフリ | ポイント受け取り | ボーナス合計 | 最終金額 |
|------|---------|----------------|------------|---------|
| **パターン1** | しない | 現金振込 | 0% | 16,273円 |
| **パターン2** | する | 現金振込 | +10% | 17,900円 |
| **パターン3** | しない | ポイント | +20% | 19,527pt |
| **パターン4** ⭐ | する | ポイント | **+30%** | **21,154pt** |

### ⭐ 最大ボーナス獲得方法

**ソクフリ + ポイント受け取り = +30%**

```
基本買取額: 16,273円
├─ ソクフリボーナス（+10%）: +1,627pt
├─ ポイント受け取りボーナス（+20%）: +3,254pt
└─ 合計獲得ポイント: 21,154pt

差額: 21,154 - 16,273 = +4,881pt お得！
```

## 🎁 追加ボーナス

### 初回購入ボーナス
- 買取ポイントで**初めて**本を購入すると **+1,000pt**
- 査定完了時または購入時に自動付与

### ランクボーナス
- ランクに応じて追加特典あり
- シルバー: 誕生月ポイント2倍
- ゴールド: 送料無料回数増加
- プラチナ: ポイント受け取り+15%（通常+20%から+15%追加）

## 💡 よくある質問

### Q1: ソクフリとポイント受け取りの違いは？
**A:** 
- **ソクフリ**: 査定結果を確認せずに自動承認 → +10%
- **ポイント受け取り**: 現金ではなくポイントで受領 → +20%
- この2つは別の選択肢で、**両方選択可能**です

### Q2: 両方選んだら本当に+30%になりますか？
**A:** はい！ソクフリ（+10%）とポイント受け取り（+20%）は**独立したボーナス**なので、**合計+30%**になります。

### Q3: 後からポイント受け取りに変更できますか？
**A:** はい、査定完了後の**期限内（例：1月10日 10:00まで）**であれば変更可能です。

### Q4: 現金振込でソクフリを選んだ場合は？
**A:** ソクフリボーナス（+10%）のみ適用され、**17,900円**が振り込まれます。

## 📝 システム実装メモ

### 基本設定
```javascript
const BASE_AMOUNT = 16273; // 基本買取額（円）
const SOKUFURI_BONUS = 0.10; // ソクフリボーナス 10%
const POINT_BONUS = 0.20; // ポイント受け取りボーナス 20%

function calculateBonus(isSokufuri, isPoint) {
    let totalBonus = 0;
    if (isSokufuri) totalBonus += SOKUFURI_BONUS;
    if (isPoint) totalBonus += POINT_BONUS;
    return Math.round(BASE_AMOUNT * (1 + totalBonus));
}

// 例
calculateBonus(true, true); // 21,154pt (最大ボーナス)
calculateBonus(true, false); // 17,900円 (現金+ソクフリ)
calculateBonus(false, true); // 19,527pt (ポイントのみ)
calculateBonus(false, false); // 16,273円 (ボーナスなし)
```
