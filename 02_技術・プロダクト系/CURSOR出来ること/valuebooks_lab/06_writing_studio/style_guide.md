# バリューブックス 執筆スタイルガイド

## 基本理念

本書の文体は、以下の三人の先達の精神を融合したものである：

### イヴォン・シュイナード（Patagonia創業者）の実践性
- **行動を伴う言葉**：理想を語るだけでなく、具体的な実践例を示す
- **ビジネスと環境の両立**：利益追求と社会的責任は矛盾しないことを証明する姿勢
- **謙虚な語り口**：成功を誇示せず、失敗から学んだ教訓を共有する

### レイチェル・カーソン（『沈黙の春』著者）の詩情
- **科学を詩に昇華する**：データや事実を、心に響く物語として語る
- **自然への畏敬**：本という「文化の森」を守る使命感
- **静かな警鐘**：声高に叫ぶのではなく、読者自身に気づかせる筆致

### ヘンリー・D・ソロー（『ウォールデン』著者）の哲学
- **簡素の美学**：必要最小限の言葉で、最大限の意味を込める
- **内省と観察**：日常の些細な出来事から普遍的な真理を引き出す
- **自律の精神**：既存の常識に囚われず、自分の頭で考える姿勢

## 文体の具体的指針

### 1. 一文の長さ
- 基本は40〜60字を目安とする
- 長い文は二つに分ける勇気を持つ
- 体言止めを効果的に使い、リズムを生む

### 2. 語彙の選択
- 専門用語は使わない。使う場合は必ず平易な言い換えを添える
- カタカナ語は最小限に。「サステナビリティ」より「持続可能性」
- 古典からの引用は、現代に通じる形で紹介する

### 3. 段落構成
- 一段落一主題の原則
- 冒頭で結論または問いを提示し、読者を引き込む
- 最後の一文で次の段落への橋渡しをする

### 4. 比喩の使い方
- 本は「種子」である。一度読まれ、人の心に根を下ろし、やがて花を咲かせる
- 古書店は「森の番人」である。文化という生態系を守り、次世代に引き継ぐ
- 顧客は「共犯者」である。本を循環させる営みに参加する仲間

### 5. 避けるべき表現
- 断定的な物言い（「〜すべきだ」「〜に違いない」）
- 自己顕示的な表現（「私は発見した」より「気づかされた」）
- 感嘆符の多用（本当に必要な場面でのみ使用）

## 章の構成テンプレート

```
【章タイトル】
具体的かつ詩的な表現。読者の好奇心を刺激する問いかけ。

【冒頭】
個人的なエピソードまたは情景描写から入る。
抽象論ではなく、具体的な「場面」を見せる。

【展開】
エピソードから得られた気づきを、より広い文脈に接続する。
データや事例を交えながら、主張を裏付ける。

【転回】
予想される反論や、自身の葛藤に正直に向き合う。
「しかし」で始まる段落を設ける。

【結び】
読者への問いかけ、または実践への招待で締める。
明確な「答え」ではなく、「問い」を残す。
```
