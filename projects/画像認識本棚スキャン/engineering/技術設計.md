## 技術スタック

| カテゴリ | 技術 | 用途 | コスト |
|---------|------|------|--------|
| 画像セグメンテーション | **SAM3** (Meta) | 本棚画像から背表紙を切り出し | - |
| OCR | **LINE OCR** | 背表紙からテキスト読み取り | 0.3円/画像 |
| OCR（高精度） | **Gemini 3 Flash** | 構造化抽出（タイトル・著者・巻数等） | 6-9円/画像 |
| 検索 | **OpenSearch 3.1** | 書誌データベース検索 | - |
| AI判定 | **GPT-5 mini** | 候補10件からの選択判定 | 0.1円以下/冊 |
| AI判定 | **Gemini 3 Flash** | 背表紙画像＋候補での最終判定 | 0.2円程度/冊 |
| 処理基盤 | **Python** | パイプライン全体 | - |

## 判定ロジック詳細

### ①ルールベースチェック

```
採用条件:
  - 候補2のスコア ≤ 候補1のスコア × 0.6
  - スコアの絶対値が閾値以上（洋書: 50点、その他: 100点）
  - 2つ以上の出版社名が含まれていない

除外条件:
  - 本棚指定なし検索で候補1が在庫データにない場合
```

### ②OpenAI AI判定

- OCRテキスト＋候補1〜10のJSONを入力
- 正解のidまたはNone（判断できない場合）を出力
- モデル: GPT-5 mini

### ③Gemini AI判定

- 背表紙画像＋候補のJSON情報を入力
- 正解のidまたはNone（判断できない場合）を出力
- モデル: Gemini 3 Flash Preview

## 既知の課題

| 課題 | 原因 | 影響 | 対策 |
|------|------|------|------|
| 洋書のスコアが低い | アルファベット単語がngram検索にならない | 足切りで不採用になりやすい | 洋書は足切り50点に緩和 |
| 雑誌棚の精度が低い | 細い背表紙が多い | SAM3の切り出し精度低下 | 雑誌は別処理を検討 |
| 似ている本の誤判定 | 巻数違い・版違い | 本棚指定なしで不正解増加 | グループ化ロジック検討 |
| 背表紙画像の欠損 | 撮影角度・付箋等 | AIが誤判定 | 事前除外の仕組み検討 |
