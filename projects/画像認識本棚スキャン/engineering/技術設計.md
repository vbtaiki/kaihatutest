## 1. システムアーキテクチャ

本システムは「本棚画像 → 書籍特定」を自動化するパイプラインです。

```
  本棚画像入力
      │
      ▼
  ┌────────────┐
  │  SAM3      │  背表紙のセグメンテーション（画像切り出し）
  └─────┬──────┘
        ▼
  ┌────────────┐
  │  OCR       │  背表紙テキストの読み取り
  │ (LINE OCR) │  + Gemini による構造化抽出
  └─────┬──────┘
        ▼
  ┌────────────┐
  │ OpenSearch  │  書誌データベースから候補を検索
  └─────┬──────┘
        ▼
  ┌────────────────────────────────────┐
  │         3段階の判定ロジック          │
  │                                    │
  │  ① ルールベース → 明確なものを確定  │
  │  ② OpenAI      → テキストで判定    │
  │  ③ Gemini      → 画像＋テキストで判定│
  └─────┬──────────────────────────────┘
        ▼
    結果出力
```

## 2. 技術スタック

### 画像処理・OCR

| 技術 | 用途 | コスト目安 |
|------|------|-----------|
| **SAM3** (Meta) | 本棚画像から背表紙を切り出し | — |
| **LINE OCR** | 背表紙からテキスト読み取り | 約 0.3 円/画像 |
| **Gemini 3 Flash** | 構造化抽出（タイトル・著者・巻数等） | 約 6〜9 円/画像 |

### 検索・判定

| 技術 | 用途 | コスト目安 |
|------|------|-----------|
| **OpenSearch 3.1** | 書誌データベース検索 | — |
| **GPT-5 mini** | テキストベースの候補選択（判定②） | 約 0.1 円以下/冊 |
| **Gemini 3 Flash** | 画像＋テキストでの最終判定（判定③） | 約 0.2 円/冊 |

### 処理基盤

| 技術 | 用途 |
|------|------|
| **Python** | パイプライン全体の実装 |

## 3. 処理パイプライン

```
本棚画像 → [SAM3] → 背表紙画像（複数） → [LINE OCR + Gemini] → テキスト情報
    → [OpenSearch] → 候補リスト → [判定①②③] → 書籍特定結果
```

各ステップの概要:

1. **SAM3 セグメンテーション**: 本棚画像を入力し、個々の背表紙領域を切り出す
2. **OCR + 構造化抽出**: LINE OCR でテキスト読み取り → Gemini でタイトル・著者・巻数などを構造化
3. **OpenSearch 検索**: 抽出テキストで書誌データベースを検索し、候補を取得
4. **3段階判定**: ルールベース → OpenAI → Gemini の順に判定（詳細は次節）

## 4. 判定ロジック詳細

候補の中から正解を特定するために、3段階の判定を行います。

### ① ルールベースチェック（高速・低コスト）

明確に判断できるものを先にフィルタリングします。

**採用条件（すべて満たす場合）:**
- 候補2のスコア ≤ 候補1のスコア × 0.6（圧倒的な差がある）
- スコアの絶対値が閾値以上
  - 洋書: **50点**
  - その他: **100点**
- 2つ以上の出版社名が含まれていない

**除外条件:**
- 本棚指定なし検索で、候補1が在庫データにない場合

### ② OpenAI AI判定（テキストベース）

ルールベースで確定できなかったものを、AIで判定します。

- **入力**: OCRテキスト ＋ 候補1〜10件のJSON
- **出力**: 正解の id / None（判断不能の場合）
- **モデル**: GPT-5 mini

### ③ Gemini AI判定（画像＋テキスト）

②でも判断できなかったものを、画像情報も使って最終判定します。

- **入力**: 背表紙画像 ＋ 候補のJSON情報
- **出力**: 正解の id / None（判断不能の場合）
- **モデル**: Gemini 3 Flash Preview

## 5. 既知の課題と対策

| # | 課題 | 原因 | 影響 | 対策状況 |
|---|------|------|------|---------|
| 1 | 洋書のスコアが低い | アルファベット単語が ngram 検索に合わない | 足切りで不採用になりやすい | ✅ 洋書は足切り **50点** に緩和済み |
| 2 | 雑誌棚の精度が低い | 細い背表紙が多い | SAM3 の切り出し精度が低下 | 🔄 雑誌は別処理を検討中 |
| 3 | 似ている本の誤判定 | 巻数違い・版違い | 本棚指定なしで不正解が増加 | 🔄 グループ化ロジックを検討中 |
| 4 | 背表紙画像の欠損 | 撮影角度・付箋等の遮蔽 | AI が誤判定する | 🔄 事前除外の仕組みを検討中 |
