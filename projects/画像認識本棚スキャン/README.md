# 📚 本棚スキャン OCR検索プロジェクト

## プロジェクト概要

**本棚の写真を撮るだけで、そこにある本を自動で特定するシステム**

背表紙画像とOCR結果を組み合わせた判定システムが完成し、
本棚指定あり検索で **正解率98.5%** を達成しています（2,031件検証）。

## 📁 このプロジェクトの見方

```
画像認識本棚スキャン/
│
├── 📋 README.md               ← いまここ
│
├── 🏢 business/               ← プロジェクトオーナーの領域
│   ├── 要件・方針.md          ← 最終的に実現したいこと
│   ├── フィードバック.md      ← テスト結果への反応・改善アドバイス
│   ├── 意思決定ログ.md        ← 決定事項の記録
│   └── コード改善案/          ← 改善提案コード
│
├── 💻 engineering/            ← エンジニアの領域
│   ├── 技術設計.md            ← 技術仕様・アーキテクチャ
│   ├── 進捗報告.md            ← テスト結果・精度レポート
│   └── 質問・相談.md          ← ビジネスへの質問
│
├── 🖥️ demo/                   ← ダッシュボード
│   └── index.html             ← ブラウザで開いて確認
│
└── 🤝 shared/                 ← 共有エリア
    ├── 議事録/                ← ミーティング記録
    └── 参考資料/
```

### 進め方

1. **プロジェクトオーナー**が `business/要件・方針.md` にゴールと方針を書く
2. **エンジニア**が `engineering/進捗報告.md` にテスト結果を報告する
3. **プロジェクトオーナー**が `business/フィードバック.md` に改善アドバイスを書く
4. エンジニアがフィードバックを受けて改善→テスト→報告のサイクルを回す
