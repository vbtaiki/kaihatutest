## このプロジェクトが自動化する工程

```
従来の手作業ワークフロー:
① データを手でExcelにまとめてクリエイティブの良し悪しを判断
② 担当者が媒体ごとの予算を会議で決める
③ デザイナーに依頼 → 数日かかる
④ 入稿ツールを手で操作
⑤ A/Bテストの結果を毎週手で集計

↓ このシステムが変える ↓

① AIが自動分析・レコメンド（リアルタイム）
② 目標入力 → AI が配分案を提示（数秒）
③ 訴求軸を指定 → AIが複数案を即時生成
④ 承認ボタン → 自動入稿
⑤ 勝ちクリエイティブが自動で次回シードに昇格
```
