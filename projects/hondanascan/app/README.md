# app/ - 開発コード

このプロジェクトの本番コード（Pythonパイプライン）は、
エンジニアの開発環境で管理されています。

## コードの構成（参考）

```
本棚スキャンパイプライン:
  1. SAM3による背表紙切り出し
  2. LINE OCRまたはGemini OCRによるテキスト読み取り
  3. OpenSearchによる書誌データベース検索
  4. ルールベースチェック → AI判定（OpenAI / Gemini）
```

## エンジニアへ

コードの変更や新しいスクリプトがある場合は、
ここにサンプルや設定ファイルを配置してください。

ビジネスサイドがコードの改善案を作った場合は、
`business/コード改善案/` に配置されます。
